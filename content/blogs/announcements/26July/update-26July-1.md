During the previous release cycle, OEM officially enabled the **Comment System**. You can now freely post comments related to markers or the game, and together with **Community Screenshots**, they can help you and other administrators with your collection progress. **Multi-image Uploads** were also enabled earlier; if an existing screenshot does not provide enough information, you can upload a better version directly.

We recommend creating an OEM account to securely sync all of your collection progress. If you find the map helpful, we would greatly appreciate you recommending OEM to fellow players.

## Recently Updated Markers

With the Version 1.4 marker update, OEM has added a dedicated **Recently Updated Markers** category. As shown in **Figure 1**, you can now use this category to quickly organize resources available in the current version and **newly added intels** on the map.

New collectible types introduced in this version have already been added to the map. If anything is still missing, we will add it as soon as it has been verified.

![Figure 1: Recently Updated Markers Overview](/blogs/announcements/26July/fig1.webp)

## Marker Detail Feature Updates

This update brings several improvements to marker detail modal. While preserving the existing lookup experience, it further strengthens community collaboration, allowing players to share guides more efficiently, add screenshots, and complete their map collection.

### Comment System

As shown in **Figure 2**, marker details now support community comments. You can share puzzle solutions, hidden routes, respawn mechanics, or other game-related content. You can also reply to and like other players' comments, or edit comments you have posted. Comments support **automatic translation**, making it easier for players speaking different languages to communicate.

![Figure 2: Comment Section](/blogs/announcements/26July/fig2.webp)

### Multi-Image Uploads

Community screenshots now support **uploading multiple images to a single marker**. As shown in **Figure 3**, when existing screenshots do not fully show a route, entrance, or mechanism detail, you can upload a new screenshot directly as a supplement without waiting for the old image to be removed.

You can browse multiple images using the left and right controls, allowing different viewpoints, moments, or solutions to be preserved on the same marker and making community guides more complete.

![Figure 3: Multi-Image Uploads](/blogs/announcements/26July/fig3.webp)

### Collect All Markers of the Same Type

OEM now includes a **Collect All Markers of the Same Type** feature for repeatable, independent resources such as chests and gathering materials. As shown in **Figure 4**, click the corresponding button on a marker detail page to mark all markers of the **same type** on the **current map** as collected at once, without selecting them one by one.

![Figure 4: Collect All Markers of the Same Type](/blogs/announcements/26July/fig4.webp)

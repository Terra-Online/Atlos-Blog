엔드필드 지도를 이용해 주셔서 감사합니다.

지난 버전 기간 동안 Open Endfield Map은 **계정 시스템**을 정식 도입했으며, **실시간 위치 동기화, 스크린샷 업로드, 공식 지도 진행도 가져오기, OEM Cloud** 등의 기능을 추가했습니다.

현재 OEM의 등록 사용자 수는 **1,200명을 돌파**했으며, 이용자들이 업로드한 스크린샷은 타로스 II 전역의 **2,700개 이상의 수집 포인트**를 커버하고 있습니다. 또한 진행도를 안전하게 동기화하기 위해 OEM 계정 등록을 권장합니다.

1.3 버전에서는 **포인트 댓글, 다중 이미지 업로드, 포인트 수집 통계, 개인 기여 대시보드** 등의 커뮤니티 기능을 순차적으로 공개할 예정이며, **터키어**와 **우크라이나어**도 새롭게 지원합니다. OEM은 전 세계 엔드필드 플레이어를 위한 최고의 지도 도구가 되는 것을 목표로 하고 있습니다. 느리고 불편한 대체 서비스나 오래되거나 부정확한 데이터에 의존할 필요가 없는 환경을 제공하고자 합니다.

OEM이 도움이 되었다고 생각하신다면 다른 엔드필드 플레이어들에게도 소개해 주시면 감사하겠습니다.

아래에서 최근 업데이트 내용을 확인하실 수 있습니다.

## 포인트 업데이트

### 레이어 표시 기능

아래 그림과 같이, 이제 메인 레이어가 아닌 포인트는 해당 레이어 정보를 표시합니다. 레이어 배지를 클릭하면 해당 레이어로 즉시 전환할 수 있어 복잡한 실내 구조에서도 더욱 편리하게 탐색할 수 있습니다.

![그림 1: 레이어 표시 예시](/blogs/announcements/26June/fig1.webp)

### 포인트 유형 업데이트

최근 추가되었거나 추가 예정인 포인트는 다음과 같습니다.

1. **「장검곡」** 의 모든 포인트
2. 재생성되는 **나무 상자** 포인트
3. 수동으로 관리되는 **NPC 상점** 위치 (예정)
4. **잠긴 보물 상자** 해제용 조각 위치 (예정)

포인트 데이터 유지 관리에 참여하고 싶으시다면 [Discord 서버](https://discord.gg/BFMAKZSUG7)에 참여해 주세요.

## 기능 업데이트

아래 그림과 같이 최근 클라우드 동기화 기능이 정식으로 활성화되었습니다. OEM 계정의 기본 기능으로서 클라우드 동기화는 **회원 가입 후 기본적으로 활성화되며 로컬 데이터를 자동으로 지속 동기화**합니다. 이를 통해 여러 기기와 브라우저 간의 데이터 일관성을 유지할 수 있습니다. 또한 기존 데이터를 병합하거나 공식 지도에서 진행도를 가져오는 기능도 지원합니다.

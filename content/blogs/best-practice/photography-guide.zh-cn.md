感谢您使用终末地地图集的图片上传功能！游戏内截图作为点位数据重要补充，能够帮助其他玩家更快地确认自己是否到达正确位置；我们衷心感谢每一位参与地图集点位图像库建设的贡献者。

为了帮助您和其他用户更好地利用这一功能，我们撰写了这篇指南，以期协助您了解最具参考价值的图片要素，以及如何拍摄与上传能够真正帮助其他玩家的内容。

## 上传须知

地图集会对您上传的图片进行规格校验及处理，我们支持符合以下条件的图片：
- 图片为 JPEG/PNG/WebP/AVIF/HEIC 格式；
- 图片体积不大于 16 MB；
- 任意分辨率的图片；我们推荐您使用 4K 或以下的分辨率的原始图片；
- 您不需要自行压缩为 WebP 格式！地图集会进行详尽的尺寸压缩和格式后处理 (◕ᴗ◕)

## 通用图片建议

关于您可以上传和不应上传的图片内容，可以在[社区守则](../../docs/community-guidelines)中找到；除此之外，一张好的图片应该具有如下的特征：

| 图片要素 | 描述 |
| :---: | :---: |
| 合理使用摄影功能 | 推荐使用游戏内摄影模式，并根据需要适当调整焦段、景深与滤镜效果，保证足够辨认的周边环境特征。 |
| 路线或解法批注 | 对于路线复杂、需要特殊移动方式抵达或者包含解谜要素的点位，可自行在图片编辑软件中补充说明，提高图片的参考价值。 |
| 防止界面元素干扰 | 您可以直接使用游戏内截图，但通常请尽量隐藏任务追踪、活动提示、以及玩家UID等关界面元素，避免造成干扰。 |
| 选择具有代表性的视角 | 优先选择玩家正常探索过程中最容易观察到的视角，避免使用过于特殊或难以复现的拍摄角度，以及仅包含点位本身导致无法辨认周围环境的视角。 |

# 支持终末地地图集

终末地地图集（Open Endfield Map）是一个由社区驱动、长期维护的**开源非盈利**项目。项目目前由少量开发者在课/业余时间持续维护，涉及：

- 地图数据整理与更新
- UI / UX 设计系统维护
- 前后端开发
- 多语言本地化
- 社区内容审核
- 工具链与自动化维护
- 服务器与 CDN 以及其他基础设施开销

我们不会在站内加入广告，也不会出售用户数据。所有支持都将直接用于项目的持续运行与未来开发。

如果你喜欢这个项目或认为它对你有所帮助，并希望它能够长期稳定维护，可以通过以下渠道支持我们。

---

# Patreon

适合希望长期订阅支持项目的用户。

## Trailblazer — $3 / month

- 支持项目持续维护
- 获得 Supporter 身份组
- Discord 专属频道访问权限
- 开发日志提前查看

## Cartographer — $7 / month

包含以上全部内容，额外获得：

- 新区域开发进度预览
- 部分实验功能抢先体验
- 月度开发总结
- 名字展示于 Supporters 页面（可选）

## Infrastructure Pioneer — $15 / month

包含以上全部内容，额外获得：

- 高优先级反馈与建议通道
- UI / 功能设计投票权
- 部分内部设计稿与技术分享
- 特殊 Discord 身份组

# Ko-fi

适合一次性支持或轻量赞助。

你可以选择：

- 请开发者喝一杯咖啡 ☕

- 无需长期订阅

Ko-fi 支持者同样会获得：

- Supporter 身份组
- 支持者页面展示（可选）

# 关于 Bonus 与支持者奖励

我们不希望支持行为影响地图本身的开放性，因此：

- 所有核心地图功能始终免费开放
- 不会出售数值或影响功能公平性的内容
- 不会锁定地图数据访问权限

支持者奖励主要集中于：

- 开发过程内容
- 抢先体验
- 社区身份
- 开发日志
- 实验功能测试资格

你的支持本质上是在帮助这个项目继续存在，并拥有更稳定的维护能力。

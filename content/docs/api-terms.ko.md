---
title: API 이용 약관
description: Open Endfield Map의 API 이용 약관입니다.
---

**Open Endfield Map**(이하 "당사", "본 프로젝트" 또는 "OEM"이라 함)에서 제공하는 응용 프로그램 프로그래밍 인터페이스(API)에 오신 것을 환영합니다. 귀하("개발자" 또는 "귀하")는 OEM API에 액세스, 통합 또는 어떠한 방식으로든 이를 사용함으로써 본 *API 이용 약관*(이하 "본 약관")을 읽고 이해했으며 그 완전한 법적 효력에 구속되는 데 동의함을 의미합니다. 본 약관의 어떠한 조항이라도 동의하지 않는 경우, 즉시 본 API에 대한 모든 액세스 및 사용을 중단해야 합니다.

---

## 계정 및 액세스 자격 증명
1. **자격 증명 보안**: OEM이 귀하에게 API 키(API Key) 또는 액세스 토큰을 할당한 경우, 귀하는 이를 엄격하게 기밀로 유지해야 합니다. 귀하는 귀하의 API 자격 증명을 제3자와 공유, 판매, 양도 또는 기타 방법으로 공개할 수 없습니다.
2. **자격 증명 책임**: 귀하는 귀하의 API 자격 증명 하에 발생하는 모든 활동에 대해 전적인 책임을 져야 합니다. 자격 증명의 손상이나 무단 사용을 발견한 경우 즉시 당사에 알려야 합니다.

---

## 허용된 사용
귀하는 개인적, 교육적 및 비상업적 목적으로 OEM API에 액세스할 수 있습니다. 당사는 개발자가 OEM의 기존 데이터를 기반으로 실질적이고 혁신적인 경험을 제공하는 파생 도구(예: 게임 루트 플래너, 리소스 육성 계산기, 데이터 분석 도구, Discord/QQ 봇 등)를 구축하도록 권장합니다. 귀하의 애플리케이션은 최종 사용자에게 공식 OEM 플랫폼을 넘어서는 **부가 가치**를 제공해야 합니다.

---

## 금지된 사용
OEM API를 사용할 때 다음 행위는 엄격히 금지됩니다.
1. **모든 형태의 상업화**: 귀하는 OEM API 또는 제공되는 데이터를 사용하여 직간접적인 수익을 창출할 수 없습니다. 여기에는 애플리케이션 내 광고 삽입, 페이월(Paywalls) 설정, 의무적인 후원/기부 요구, 또는 애플리케이션을 유료 소프트웨어로 판매하는 행위가 포함되나 이에 국한되지 않습니다. 상업적 승인이 필요한 경우 사전에 OEM 팀의 서면 동의를 얻어야 합니다.
2. **미러링, 포팅 또는 복제본 개발**: 귀하는 본 API를 사용하여 OEM의 지도 콘텐츠 및 대화형 인터페이스를 "있는 그대로" 복제, 표시 또는 재배포할 수 없습니다. 공식 OEM 웹사이트를 대체하거나 트래픽을 분산시키기 위해 설계된 래퍼(Wrapper) 또는 복제 애플리케이션의 개발은 엄격히 금지됩니다.
3. **대량 스크래핑 및 데이터 세트 재판매**: 귀하는 본 API의 기본 데이터(예: 전체 좌표 데이터 또는 도감 텍스트)를 대량으로 다운로드, 스크랩 또는 추출하여 독립적인 오프라인 데이터 세트로 사용하거나 귀하의 자체 API를 통해 해당 데이터를 재배포할 수 없습니다.
4. **남용 및 방해**: 귀하는 OEM의 서버 및 네트워크를 방해, 과부하 또는 손상시킬 수 있는 어떠한 방식으로도 본 API를 사용할 수 없습니다(DDoS 공격, 취약점을 악용한 악성 코드 주입 등 포함하되 이에 국한되지 않음).

---

## 호출 제한 및 캐싱 정책
1. **호출 빈도 제한 준수**: 귀하는 API 응답 헤더(Headers) 또는 공식 문서에 명시된 OEM의 호출 빈도 제한(Rate Limits)을 준수해야 합니다. 다중 IP 회전, 위조된 User-Agent 또는 기타 우회적인 기술적 수단을 통해 이러한 제한을 회피하는 것은 엄격히 금지됩니다.
2. **합리적인 캐싱**: 당사의 서버 리소스를 보호하기 위해 귀하는 애플리케이션 내에 합리적인 로컬 캐싱(Caching) 전략을 구현해야 합니다. 정적이거나 거의 수정되지 않는 데이터에 대한 빈번하고 반복적인 요청은 피해야 합니다.

---

## 지적 재산권 및 브랜드 식별
1. **데이터 소유권**: 본 API를 통해 액세스되는 기본적인 지도 데이터, 이미지 리소스, 마커 정보 및 사용자 생성 콘텐츠(UGC)에 대한 모든 소유권 및 지적 재산권은 전적으로 Open Endfield Map 및 각 기여자에게 있습니다.
2. **브랜드 경계**: 사전 서면 동의 없이 귀하는 애플리케이션 이름, 로고 또는 도메인 이름에 "Open Endfield Map" 또는 혼동을 일으킬 수 있는 유사한 이름을 사용할 수 없습니다. 귀하는 귀하의 애플리케이션이 OEM의 "공식 제품"이거나 OEM으로부터 공식적인 승인을 받았음을 암시할 수 없습니다.

---

## 출처 표기 요구 사항
본 API를 활용하여 공개 서비스를 구축하는 경우, 귀하의 애플리케이션 인터페이스의 눈에 띄는 위치(예: 바닥글 또는 "정보" 페이지)에 공식 OEM 웹사이트로 연결되는 유효한 하이퍼링크를 포함하여 명확한 출처 표기를 제공해야 합니다.
*예시 문구: "본 애플리케이션의 지형 및 좌표 데이터는 [Open Endfield Map](https://openendfieldmap.com)에서 지원합니다."*

---

## 개인정보 및 사용자 데이터
귀하의 애플리케이션이 최종 사용자의 개인 정보를 처리하는 경우, 귀하는 법적으로 준수되는 *개인정보 처리방침*을 제공해야 합니다. 귀하는 OEM API를 사용하여 OEM 플랫폼의 다른 사용자의 개인 프라이버시 데이터 또는 계정 정보를 수집, 디컴파일 또는 액세스하려고 시도해서는 안 됩니다.

---

## 해지 및 액세스 권한 취소
OEM은 언제든지 어떠한 이유로든(귀하가 본 약관을 위반했다는 합리적인 의심을 포함하되 이에 국한되지 않음) 귀하의 API 액세스 권한을 일방적으로 제한, 일시 중단 또는 영구적으로 해지할 권리를 보유합니다. 당사는 이러한 조치를 취할 때 사전 통지를 제공할 의무가 없으며 귀하나 제3자에게 어떠한 책임도 지지 않습니다.

---

## 보증의 부인
본 API 및 모든 관련 데이터는 "있는 그대로(As Is)" 및 "이용 가능한 상태로(As Available)" 제공됩니다. OEM은 상품성, 특정 목적에의 적합성, 데이터의 정확성, 비침해 또는 중단 없는 서비스에 대한 보증을 포함하되 이에 국한되지 않는 모든 명시적 또는 묵시적 보증을 명시적으로 부인합니다.

---

## 책임 제한 및 면책
1. **책임 제한**: 해당 법률이 허용하는 최대 한도 내에서 OEM 및 그 기여자는 귀하의 본 API 사용 또는 사용 불능으로 인해 발생하는 모든 직간접적, 우발적, 특수한 또는 징벌적 손해(데이터 손실 또는 이익 손실 포함)에 대해 책임을 지지 않습니다.
2. **면책**: 귀하는 귀하의 본 약관 위반, API 남용 또는 귀하의 애플리케이션이 제3자의 권리를 침해함으로 인해 발생하는 어떠한 청구, 소송 또는 요구(합리적인 변호사 비용 포함)로부터 OEM을 완전히 면책시키고 방어하며 피해를 입지 않도록 하는 데 동의합니다.

---

Добро пожаловать в API **Open Endfield Map** (далее - «OEM», «мы» или «Проект»). Используя API, вы соглашаетесь с настоящими условиями. Если вы не согласны с ними, немедленно прекратите доступ к API.

---

## Область и стабильность API

1. **Публичный API**: только явно опубликованные OEM конечные точки и поля предназначены для сторонних интеграций. Конечные точки клиента для учетных записей, прогресса, привязки персонажей, загрузок, модерации и администрирования не становятся публичным API только потому, что их можно увидеть в браузере.
2. **Аутентифицированные интерфейсы**: интерфейсы, требующие сессии, Bearer Token или иных учетных данных, можно использовать только с явным разрешением соответствующего пользователя и в рамках предусмотренного продукта процесса. Нельзя повторно использовать, передавать или побуждать пользователей передавать Cookie сессии, игровые токены либо иные чувствительные данные.
3. **Возможность изменений**: интерфейсы без обещанной стабильной версии, их поля ответа, ограничения частоты и правила кэширования могут изменяться, переноситься или прекращаться вместе с обновлениями клиента и сервера. Сторонние приложения должны обрабатывать ошибки и изменения версий самостоятельно.

## Учетные данные и доступ

1. Храните выданные API-ключи и токены в тайне и не передавайте их третьим лицам.
2. Вы несете ответственность за действия, выполненные с использованием ваших учетных данных, и должны немедленно сообщить нам об их компрометации.

## Разрешенное и запрещенное использование

API разрешается использовать в личных, учебных и некоммерческих целях для инструментов, создающих дополнительную ценность, например планировщиков маршрутов, калькуляторов ресурсов, аналитики и ботов.

Запрещается коммерциализировать API или его данные, создавать зеркала и заменители OEM, массово выгружать или перепродавать наборы данных, обходить ограничения частоты, нарушать работу сервисов либо внедрять вредоносный код.

## Ограничения, права и указание авторства

Соблюдайте опубликованные ограничения частоты и используйте разумное локальное кэширование. Игровые ресурсы, оригинальный контент OEM и пользовательский контент принадлежат соответствующим правообладателям, OEM, авторам или отправителям. Доступность API не передает права и не расширяет лицензию на использование такого контента.

Нельзя использовать название, логотип или домен OEM без письменного согласия либо создавать впечатление официального одобрения. В публичном сервисе необходимо заметно указать OEM и дать действующую ссылку на официальный сайт.

## Конфиденциальность, прекращение и ответственность

При обработке персональных данных пользователей предоставьте законную политику конфиденциальности. Не пытайтесь получать персональные данные или данные учетных записей других пользователей OEM.

OEM может ограничить, приостановить или прекратить доступ при нарушении этих условий. API и данные предоставляются «как есть» и «по мере доступности» без гарантий. В максимальной степени, разрешенной законом, OEM и его участники не отвечают за убытки, а вы обязуетесь возместить претензии, вызванные вашим нарушением, злоупотреблением API или нарушением прав третьих лиц.

## 介面範圍及穩定性

1. **公開介面**：只有 OEM 明確發佈為公共開發者介面的端點及欄位，方屬可供第三方整合的 API。地圖用戶端所使用的帳戶、進度、遊戲角色綁定、上載、審核及管理端點，不會僅因可從瀏覽器中觀察而自動成為公共 API。
2. **認證介面**：需要登入工作階段、Bearer Token 或其他用戶憑證的介面，只可在相應用戶主動授權並符合產品流程時使用。不得重用、代為傳送或誘使用戶提交工作階段 Cookie、遊戲授權權杖等敏感憑證。
3. **可能變更**：未承諾穩定版本的介面、回應欄位、頻率限制及快取策略，可能隨用戶端與後端更新而調整、遷移或停止提供。第三方應用程式須自行處理錯誤及版本變更。

1. **憑證安全**：如 OEM 向閣下分配 API 金鑰（API Key）或存取權杖，閣下必須嚴格保密。閣下不得與任何第三方分享、出售、轉讓或以其他方式洩露 API 憑證。
2. **憑證責任**：閣下須就使用其 API 憑證進行的一切活動承擔全部責任。如發現憑證外洩或遭未經授權使用，閣下必須立即通知我們。

## 允許用途
閣下可為個人、學習及非商業目的存取 OEM API。我們鼓勵開發者在 OEM 現有資料的基礎上，建立能提供實質創新體驗的衍生工具（例如遊戲路線規劃工具、資源養成計算器、數據分析工具、Discord／QQ 機械人等）。閣下的應用程式必須為最終用戶提供 OEM 官方平台以外的**附加價值**。

---

## 禁止用途
閣下使用 OEM API 時，嚴禁進行以下行為：
1. **任何形式的商業化**：閣下不得利用 OEM API 或其提供的資料取得任何直接或間接收入，包括但不限於在應用程式中加入廣告、設置付費訂閱（Paywalls）、強制贊助／打賞，或將應用程式作為付費軟件出售。如需商業授權，必須事先取得 OEM 團隊的書面許可。
2. **鏡像、搬運或開發替代品**：閣下不得使用本 API「原樣」複製、展示或重新分發 OEM 的地圖內容與互動介面。嚴禁利用本 API 開發旨在替代 OEM 官方網站、分流其流量的套殼複製品。
3. **大量擷取及轉售資料集**：閣下不得大規模下載、擷取或提取本 API 的基礎資料（例如全部座標點位、圖鑑文字），並將其作為獨立的離線資料集，或透過閣下自設的 API 再次分發。
4. **濫用及破壞**：閣下不得以任何可能破壞 OEM 伺服器及網絡、使其超出負荷或受損的方式使用本 API，包括但不限於 DDoS 攻擊、利用漏洞注入惡意程式碼等。

## 呼叫限制及快取策略
1. **遵守頻率限制**：閣下必須遵守 OEM 在 API 回應標頭（Headers）或官方文檔中訂明的呼叫頻率限制（Rate Limits）。嚴禁透過輪換多個 IP、偽造 User-Agent 等方式規避限制。
2. **合理快取**：為保障我們的伺服器資源，閣下應在應用程式中採用合理的本機快取（Caching）策略，避免頻繁重複請求靜態或極少變更的資料。

## 署名要求
如閣下使用本 API 建立公開服務，必須在應用程式介面的顯眼位置（例如頁尾、關於頁面）清楚註明資料來源，並加入指向 OEM 官方網站的有效超連結。
*聲明範例：「本應用程式的地形與座標資料由 [Open Endfield Map](https://openendfieldmap.com) 提供支援。」*

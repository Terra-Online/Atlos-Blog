本文件是[《UGC 内容声明》](./ugc)的补充，适用于点位图片、评论、回复、投票、举报及其他社区互动。

## 基本原则

- 尊重其他用户，围绕地图探索提供客观、相关且有帮助的信息；
- 不蓄意误导玩家、污染点位内容或操纵社区互动；
- 遵守适用法律，不滥用上传、评论、翻译、举报、投票或 API 能力；
- 保护自己和他人的隐私，不公开密码、令牌、联系方式或其他敏感信息。

## 内容规范

| 内容类型 | 允许的内容 | 禁止的内容 |
| :--- | :--- | :--- |
| **截图与图像** | <ul><li>清晰展示游戏点位、场景或路线的第三视角截图</li><li>用于辅助说明地图机制、地形结构或隐藏内容的图片</li><li>适度裁剪、压缩或标注后的辅助指引图</li></ul> | <ul><li>包含真实姓名、联系方式、账号密码、聊天记录等敏感个人信息的图片</li><li>与《明日方舟：终末地》无关或无意义的图片</li><li>带有外挂宣传、水印广告、恶意二维码或引流内容的图片</li><li>涉及色情、暴力、血腥、恐怖主义、仇恨或政治敏感内容的图片</li><li>明显误导玩家、伪造点位或恶意污染地图的数据截图</li></ul> |
| **评论、文本与描述** | <ul><li>客观的点位说明与路线建议</li><li>有建设性的纠错反馈</li><li>与地图探索相关的经验分享与社区交流</li></ul> | <ul><li>侮辱、诽谤、人身攻击或恶意骚扰内容</li><li>歧视性、仇恨性或极端主义言论</li><li>外挂、作弊、私服或破坏游戏公平性的传播内容</li><li>垃圾广告、恶意刷屏或重复灌水</li><li>恶意代码、脚本、钓鱼信息或账号诈骗内容</li><li>未经授权披露他人隐私或账号信息的文本内容</li></ul> |
| **点位与数据** | <ul><li>经实际验证的游戏内点位与坐标</li><li>合理的采集路线、探索路径与地图标注</li></ul> | <ul><li>明显错误、恶意伪造或误导性的地图信息</li><li>大量重复、无意义或自动化生成的数据</li><li>利用接口批量灌入非法点位或异常数据的行为</li></ul> |
| **投票与举报** | 根据内容质量表达真实评价；针对具体违规问题提交善意举报 | 多账号操纵、报复性举报、批量骚扰、虚假举报或借助自动化工具影响内容排序与审核 |

## 提交、审核与公开展示

1. 图片和评论提交后先进入自动审核；系统会同时审核文字与图片。未能自动通过的内容进入人工复核。
2. 内容审核通过后会公开展示。审核中、待人工复核或被撤回的内容通常不会向其他普通访问者展示。
3. 评论编辑后需要重新审核；在新版本通过前，系统可保留原公开版本或编辑快照。
4. 公开评论可预生成或按需生成机器翻译。机器翻译可能不准确，不应被视为作者原文。
5. 举报会触发状态变更或复核流程。举报数量不等同于违规结论，管理人员会结合内容和上下文处理。

## 违规处置

我们可以根据违规程度隐藏、拒绝、标记、撤回或删除内容，并限制严重或反复违规账户的互动能力。提交者可以在产品允许的状态下撤回内容，或对公开内容提出删除申请。

UGC 由用户独立提交，本项目不保证其绝对准确。请结合游戏实际情况核实图片、评论和路线建议。

涉及森空岛或 SKPORT 角色绑定与实时定位时，还可能存在第三方接口变更、授权失效或游戏服务方风控风险，详见[《责任豁免声明》](./disclaimer)。

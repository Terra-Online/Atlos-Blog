本文件是[《UGC 內容聲明》](./ugc)的補充文件，適用於現有或日後提供的點位圖片、評論、回覆、點位及路線貢獻、投票、舉報及其他社群互動。

## 基本原則

- 尊重其他用戶，並就地圖探索提供客觀、相關而有用的資料；
- 不得蓄意誤導玩家、污染點位內容或操縱社群互動；
- 遵守適用法律，不得濫用上載、評論、翻譯、舉報、投票或 API 功能；
- 保障自己及他人的私隱，不得公開密碼、權杖、聯絡資料或其他敏感資料。

## 內容規範

| 內容類型 | 允許內容 | 禁止內容 |
| :--- | :--- | :--- |
| **截圖及圖像** | <ul><li>清晰展示遊戲點位、場景或路線的第三視角截圖</li><li>用於輔助說明地圖機制、地形結構或隱藏內容的圖片</li><li>經適度裁剪、壓縮或標註的輔助指引圖</li></ul> | <ul><li>包含真實姓名、聯絡方式、帳戶密碼、聊天紀錄等敏感個人資料的圖片</li><li>與《明日方舟：終末地》無關或沒有意義的圖片</li><li>帶有外掛宣傳、水印廣告、惡意二維碼或引流內容的圖片</li><li>涉及色情、暴力、血腥、恐怖主義、仇恨或政治敏感內容的圖片</li><li>明顯誤導玩家、偽造點位或惡意污染地圖資料的截圖</li></ul> |
| **評論、文字及描述** | <ul><li>客觀的點位說明及路線建議</li><li>具建設性的修正回饋</li><li>與地圖探索相關的經驗分享及社群交流</li></ul> | <ul><li>侮辱、誹謗、人身攻擊或惡意騷擾內容</li><li>歧視、仇恨或極端主義言論</li><li>外掛、作弊、私服或破壞遊戲公平性的傳播內容</li><li>垃圾廣告、惡意洗版或重複灌水</li><li>惡意程式碼、指令碼、網絡釣魚資料或帳戶詐騙內容</li><li>未經授權披露他人私隱或帳戶資料的文字內容</li></ul> |
| **點位及資料** | <ul><li>經實際驗證的遊戲內點位及座標</li><li>合理的採集路線、探索路徑及地圖標註</li></ul> | <ul><li>明顯錯誤、惡意偽造或具誤導性的地圖資料</li><li>大量重複、沒有意義或自動化產生的資料</li><li>利用介面大量灌入非法點位或異常資料的行為</li></ul> |
| **投票及舉報** | 按內容質素作出真實評價；就具體違規問題作出真誠舉報 | 多帳戶操縱、報復性舉報、大規模騷擾、虛假舉報，或利用自動化工具影響內容排序及審核 |

## 提交、審核及公開展示

1. 新圖片及評論提交後會先進入自動審核，經編輯的評論亦會重新審核；系統會分別審核相關文字及圖片。未能自動通過的內容會交由人工覆核。
2. 內容通過審核後會公開展示。審核中、等待人工覆核或已撤回的內容，通常不會向其他普通訪客展示。
3. 評論經編輯後須重新審核；在新版本通過前，系統可保留原有公開版本或編輯快照。
4. 公開評論可預先產生或按需要產生機器翻譯。機器翻譯可能不準確，不應視為作者原文。
5. 舉報會觸發狀態變更或覆核程序。舉報數量不等同違規結論，管理人員會按內容及上下文處理。

## 違規處理

我們可按違規程度隱藏、拒絕、標記、撤回或刪除內容，並限制嚴重或多次違規帳戶的互動功能。提交者可在產品容許的狀態下撤回內容，或就公開內容提出刪除要求。

UGC 由用戶獨立提交，本項目不保證其絕對準確。請按遊戲實際情況核實圖片、評論及路線建議。

涉及森空島或 SKPORT 角色綁定及實時定位時，亦可能出現第三方介面變更、授權失效或遊戲服務供應商風險監控等風險；詳情請參閱[《免責聲明》](./disclaimer)。

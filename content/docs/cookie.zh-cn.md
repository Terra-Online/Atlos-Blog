欢迎使用 **Open Endfield Map**（以下简称“我们”、“本项目”或“OEM”）。本政策说明地图客户端如何使用或管理 `Cookie`、`LocalStorage`、`SessionStorage`、`IndexedDB` 与 `Cache Storage`，以及登录后哪些数据会发送至服务器。

> 本政策是[《使用条款》](./tos)与[《隐私权政策》](./privacy)的补充文件。

## Cookie 与本地存储的用途

本项目按用途使用以下浏览器存储机制：

1. **登录 `Cookie`**：账户系统使用安全 Cookie 维持登录会话。OAuth 登录过程中也可能由相应身份提供商设置必要 Cookie。
2. **`LocalStorage`**：用于保存语言、主题、侧边栏状态、筛选器顺序、地图视图、点位完成状态、公告阅读状态及其他客户端偏好。
3. **`SessionStorage`**：可用于保存当前标签页生命周期内的临时状态；应用内存储管理器也可以检查和清除这些数据。
4. **`IndexedDB` 与 `Cache Storage`**：浏览器或应用可用其缓存资源和结构化数据，以加快后续访问；应用内存储管理器可以检查和清除同源数据库与缓存。

具体键名和保存内容会随版本调整。Cloudflare 安全服务及第三方登录服务也可能设置由其管理的必要 Cookie。

## 未登录时的数据行为

未登录时，点位完成状态、地图视图和 UI 偏好保存在当前浏览器中。清除站点数据、使用无痕窗口、更换浏览器或设备后，这些数据可能无法恢复。

浏览地图仍会向我们的服务器和 CDN 请求地图数据、图片、瓦片及公共 UGC，因此“本地保存交互状态”并不表示访问过程中不会产生普通网络请求或安全日志。

## 登录后的进度同步

登录后，客户端可将您的**点位完成状态**同步到云端，以便在不同设备间合并和恢复探索进度。同步内容以点位 ID 集合及其版本、校验和、更新时间等必要元数据表示。

以下数据目前仍保存在浏览器本地，不属于云端进度同步范围：

- 主题、语言和侧边栏状态；
- 筛选器顺序、图层显示偏好和地图视图；
- 公告阅读状态及其他 UI 偏好。

公开图片和评论属于单独的 UGC 服务，并非本地偏好的“云端备份”。游戏角色定位绑定也有独立的数据处理流程，详见[《个人信息收集与使用清单》](./data-collection)。

## 服务端存储与缓存

- **Cloudflare D1**：保存账户资料、会话、点位进度元数据、游戏角色绑定记录及 UGC 结构化记录。
- **Cloudflare R2**：保存用户提交并经处理的点位图片。
- **Cloudflare KV、Durable Objects 与 Cache API**：用于公共读取缓存、进度同步协调和统计等运行用途。
- **Upstash Redis**：用于部分接口限流和短期缓存，不作为 UI 偏好或点位进度的主要持久化数据库。

数据通过 HTTPS/TLS 传输。我们不会出售您的同步数据，也不会将其用于定向广告。

## 您的控制方式

1. **停止后续同步**：退出登录后，新的点位操作会继续保存在本地，但不会以您的账户身份同步到云端。
2. **管理本地数据**：您可以使用应用内的存储管理功能，或通过浏览器设置清除本项目的 Cookie、站点数据和缓存。清除操作可能同时移除登录状态、点位进度和界面偏好。
3. **管理云端数据**：清除浏览器数据不会自动删除已同步到服务器的账户、进度或 UGC。若需访问、更正或删除服务器端个人数据，请参阅[《隐私权政策》](./privacy)。
4. **限制 Cookie**：禁用必要 Cookie 可能导致登录、进度同步、UGC 提交和定位绑定等认证功能不可用；公共地图浏览通常仍可使用。

## 第三方基础设施

本项目使用 Cloudflare 提供 CDN、DDoS 防护和边缘计算。Cloudflare 可能根据访问风险设置安全 Cookie，并处理 IP 地址、请求头等网络信息。使用 Google、Discord 或 GitHub 登录时，相应平台也会依据其隐私政策处理认证请求。

## 我们为何使用这些技术

我们使用 Cookie 及相关存储技术的目的分为以下四大类，每一类都对保障和提升您的使用体验至关重要：

1. **维持网站核心功能（必要性操作）**
   - **会话维护**：确保您在登录后浏览不同页面时保持登录状态，无需重复验证。
   - **安全防御**：使用安全 Cookie 属性、来源校验和身份验证措施，降低会话被盗用或跨站请求等风险。
   - **API 校验**：确保所有发往服务器的数据请求均来自合法且经过授权的客户端。

2. **提升性能与用户体验（功能性操作）**
   - **状态记忆**：记住您的界面偏好（如暗黑模式/明亮模式）、语言选择以及上一次离开时的地图层级与坐标。
   - **资源优化**：缓存部分静态资源或数据索引，大幅缩短地图和图鉴的加载时间。

3. **安全与合规保障**
   - **异常流量检测**：识别并拦截自动化脚本（Bot）、DDoS 攻击等异常访问，维护平台整体稳定性。
   - **合规审计**：在发生安全事件时，提供必要的基础日志支持。

4. **汇总统计与服务改进**
   - **进度统计**：云端进度同步可用于生成各点位的完成次数及同步用户总数，以改进地图内容和功能。
   - **使用分析**：我们可在依法提供告知或取得同意后，使用去标识化的访问与功能使用统计改进服务；如启用非必要分析 Cookie 或第三方分析工具，我们会同步更新本政策及相关控制选项。

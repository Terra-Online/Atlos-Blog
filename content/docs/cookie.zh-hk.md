歡迎使用 **Open Endfield Map**（以下簡稱「我們」、「本項目」或「OEM」）。本政策說明地圖用戶端如何使用或管理 `Cookie`、`LocalStorage`、`SessionStorage`、`IndexedDB` 及 `Cache Storage`，以及登入後哪些資料會傳送至伺服器。

> 本政策是[《使用條款》](./tos)及[《私隱政策》](./privacy)的補充文件。

---

## Cookie 及本機儲存的用途

本項目按用途使用以下瀏覽器儲存機制：

1. **登入 `Cookie`**：帳戶系統使用安全 Cookie 維持登入工作階段。OAuth 登入過程中，相關身份服務供應商亦可能設定必要 Cookie。
2. **`LocalStorage`**：用於保存語言、主題、側邊欄狀態、篩選器次序、地圖視圖、點位完成狀態、公告閱讀狀態及其他用戶端偏好。
3. **`SessionStorage`**：可用於保存目前分頁有效期間內的暫存狀態；應用程式內的儲存空間管理工具亦可檢查及清除該等資料。
4. **`IndexedDB` 及 `Cache Storage`**：瀏覽器或應用程式可用其快取資源及結構化資料，以加快日後存取速度；應用程式內的儲存空間管理工具可檢查及清除同源資料庫及快取。

具體鍵名及所保存內容會隨版本調整。Cloudflare 安全服務及第三方登入服務亦可能設定由其管理的必要 Cookie。

## 未登入時的資料處理

未登入時，點位完成狀態、地圖視圖及介面偏好會保存在目前的瀏覽器。清除網站資料、使用無痕視窗，或更換瀏覽器或裝置後，該等資料可能無法復原。

瀏覽地圖時仍會向我們的伺服器及 CDN 請求地圖資料、圖片、圖磚及公開 UGC，因此「互動狀態保存在本機」並不表示存取過程中不會產生一般網絡請求或安全日誌。

---

## 登入後的進度同步

登入後，用戶端可將閣下的**點位完成狀態**同步至雲端，以便在不同裝置之間合併及復原探索進度。同步內容以點位 ID 集合及其版本、校驗和、更新時間等所需中繼資料表示。

以下資料目前仍保存在瀏覽器本機，不屬於雲端進度同步範圍：

- 主題、語言及側邊欄狀態；
- 篩選器次序、圖層顯示偏好及地圖視圖；
- 公告閱讀狀態及其他介面偏好。

公開圖片及評論屬獨立的 UGC 服務，並非本機偏好的「雲端備份」。遊戲角色定位綁定亦有獨立的資料處理流程；詳情請參閱[《個人資料收集及使用清單》](./data-collection)。

## 伺服器端儲存及快取

- **Cloudflare D1**：保存帳戶資料、工作階段、點位進度中繼資料、遊戲角色綁定紀錄及 UGC 結構化紀錄。
- **Cloudflare R2**：保存用戶提交及經處理的點位圖片。
- **Cloudflare KV、Durable Objects 及 Cache API**：用於公開讀取快取、協調進度同步及統計等系統運作用途。
- **Upstash Redis**：用於部分介面限流及短期快取，不會用作介面偏好或點位進度的主要持久資料庫。

資料透過 HTTPS/TLS 傳輸。我們不會出售閣下的同步資料，亦不會將其用於定向廣告。

---

## 閣下的控制方式

1. **停止其後同步**：登出後，新的點位操作會繼續保存在本機，但不會以閣下的帳戶身份同步至雲端。
2. **管理本機資料**：閣下可使用應用程式內的儲存管理功能，或透過瀏覽器設定清除本項目的 Cookie、網站資料及快取。清除操作可能同時移除登入狀態、點位進度及介面偏好。
3. **管理雲端資料**：清除瀏覽器資料不會自動刪除已同步至伺服器的帳戶、進度或 UGC。如需查閱、更正或刪除伺服器端個人資料，請參閱[《私隱政策》](./privacy)。
4. **限制 Cookie**：停用必要 Cookie 可能導致登入、進度同步、提交 UGC 及定位綁定等認證功能無法使用；公開地圖瀏覽一般仍可使用。

## 第三方基礎設施

本項目使用 Cloudflare 提供 CDN、DDoS 防護及邊緣運算。Cloudflare 可按存取風險設定安全 Cookie，並處理 IP 地址、請求標頭等網絡資料。使用 Google、Discord 或 GitHub 登入時，相關平台亦會按其私隱政策處理認證請求。

## 我們使用該等技術的原因

我們使用 Cookie 及相關儲存技術的目的分為以下四大類，每一類均有助保障及提升閣下的使用體驗：

1. **維持網站核心功能（必要操作）**
   - **維持工作階段**：確保閣下登入後瀏覽不同頁面時保持登入狀態，毋須重複驗證。
   - **安全防禦**：使用安全 Cookie 屬性、來源驗證及身分驗證措施，降低工作階段遭盜用或跨網站請求等風險。
   - **API 驗證**：確保所有傳送至伺服器的資料請求均來自合法及獲授權的用戶端。

2. **提升效能及用戶體驗（功能操作）**
   - **記錄狀態**：記錄閣下的介面偏好（例如深色模式／淺色模式）、語言選擇，以及上次離開時的地圖層級及座標。
   - **資源最佳化**：快取部分靜態資源或資料索引，大幅縮短地圖及圖鑑的載入時間。

3. **安全及合規保障**
   - **偵測異常流量**：識別及攔截自動化指令碼（Bot）、DDoS 攻擊等異常存取，維持平台整體穩定性。
   - **合規審計**：發生安全事故時，提供所需的基礎日誌支援。

4. **總體統計及改善服務**
   - **進度統計**：雲端進度同步可用於產生各點位的完成次數及同步用戶總數，以改善地圖內容及功能。
   - **使用情況分析**：我們可在依法作出通知或取得同意後，使用經去識別化的瀏覽及功能使用統計改善服務；如啟用非必要分析 Cookie 或第三方分析工具，我們會同步更新本政策及相關控制選項。

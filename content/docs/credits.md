## Game intellectual property

Open Endfield Map is an unofficial, non-commercial, open-source community project. Arknights: Endfield images, text, icons, audio, base maps, and game data belong to [Hypergryph](https://www.hypergryph.com/), [Gryphline](https://www.gryphline.com/en-us/home), and their respective rightsholders. They are used to represent game elements; OEM claims no ownership and will address valid rightsholder removal requests.

## User-generated content

Users submit images, comments, routes, and corrections. Authors retain rights in their original work and grant OEM the license needed to operate, review, translate, display, and maintain it. Publication, withdrawal, and removal are governed by the [UGC Statement](./ugc) and [Community Guidelines](./community-guidelines).

## Infrastructure and open source

The service uses Cloudflare for delivery, computing, and storage; Upstash for rate limits and short caches; OpenAI for moderation; Google Cloud Translation for approved-comment translations; Resend for email; and Google, Discord, and GitHub for optional OAuth sign-in. Project source and applicable dependency licenses are available in the [Atlos repository](https://github.com/Terra-Online/Atlos). Project code is licensed under AGPL v3.0.

## Игровая интеллектуальная собственность

Open Endfield Map - неофициальный некоммерческий открытый проект сообщества. Все связанные с Arknights: Endfield изображения, тексты, значки, аудио, базовые карты и игровые данные принадлежат [Hypergryph](https://www.hypergryph.com/), [Gryphline](https://www.gryphline.com/en-us/home) и соответствующим правообладателям. Они используются для отображения игровых элементов; OEM не заявляет права на них и выполнит обоснованный запрос правообладателя на удаление.

## Пользовательский контент

Изображения, комментарии, маршруты и исправления добавляются пользователями. Авторы сохраняют права на оригинальный материал и предоставляют OEM лицензию, необходимую для работы, проверки, перевода, показа и обслуживания. Условия публикации, отзыва и удаления описаны в [Заявлении о UGC](./ugc) и [Правилах сообщества](./community-guidelines).

## Инфраструктура и открытый код

Сервис использует Cloudflare для доставки, вычислений и хранения, Upstash для лимитов и краткого кэша, OpenAI для модерации, Google Cloud Translation для перевода одобренных комментариев, Resend для писем и Google, Discord и GitHub для необязательного OAuth-входа. Исходный код и применимые условия открытых зависимостей доступны в [репозитории Atlos](https://github.com/Terra-Online/Atlos); код проекта распространяется на условиях AGPL v3.0.

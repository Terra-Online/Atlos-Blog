## 機能ごとのデータ

アカウントとログインではメール、ニックネーム、アバター番号、パスワードハッシュ、又は OAuth 提供者の識別子と公開情報を D1 で処理します。進行状況同期は完了地点 ID、バージョン、チェックサム、更新時刻、競合解決用識別子だけを扱い、UI 設定や閲覧履歴は同期しません。キャラクター連携では Skland/SKPORT トークン、UID、サーバー、名前、必要な端末データを扱い、トークンは AES-GCM で暗号化します。現在地はリクエスト、WebSocket、短期メモリキャッシュで処理され、移動履歴やヒートマップは保存しません。

画像は R2、メタデータ・コメント・投票・通報・審査状態は D1 に保存します。画像とコメントは OpenAI Moderation API で審査される場合があり、承認済みコメントは Google Cloud Translation で翻訳されます。Cloudflare は基盤、Upstash は短期の制限、Resend はアカウントメールを提供します。承認された画像とコメントは公開されます。


**Open Endfield Map** へようこそ。当社が各コアビジネス機能を利用する際にお客様の個人情報をどのように収集および使用するかを明確かつ直感的に理解していただくため、本チェックリストを作成しました。

> **提示**：本チェックリストは『[プライバシーポリシー](./privacy)』の要約および補足です。当社は「ローカルファースト」および「データ最小化」の原則を堅持しており、お客様が特定のクラウド機能またはクロスデバイス機能を自発的に有効にした場合にのみ、対応するデータを収集します。

## サードパーティとの共有およびデータの越境移転

本プロジェクトは、グローバル化された分散型アーキテクチャ（Serverless & Edge Computing）を利用して展開されています。お客様が本プロジェクトの同期機能またはインタラクティブ機能を利用する際、暗号化されたデータの一部またはリクエストの特徴は、処理のためにお客様の所在する国/地域外のサーバーに合法的に転送される場合があります。

1. **インフラストラクチャとストレージの流通**：当社は基礎となるサービスを提供するために、**Cloudflare**（グローバルCDNおよびエッジデータベース）と **Upstash**（グローバルに分散されたServerless Redis）に依存しています。お客様のデータは、ネットワークの最適なルーティング戦略に基づき、海外のノードで暗号化処理および永続的な保存が行われる可能性があります。
2. **コンプライアンス審査の共有**：お客様が公開のUGCコンテンツ（コメントなど）を送信する際、関連するテキストデータは、自動化されたセキュリティ鑑別のために **OpenAI** の審査インターフェース（Moderation API）に短期間転送される場合があります。当社は、上記のサードパーティプロバイダーが厳格なデータ処理契約（DPA）の制約を受けており、お客様のデータを無関係な商業目的やAIモデルのトレーニングに使用しないことをお約束します。

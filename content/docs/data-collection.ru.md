Этот перечень дополняет [Политику конфиденциальности](./privacy). Мы обрабатываем данные только при использовании соответствующей функции.

## Функции и данные

| Функция | Данные | Цель и хранение |
| :--- | :--- | :--- |
| Учетная запись и вход | Email, имя, номер аватара, хеш пароля; либо идентификатор и открытые сведения Google, Discord или GitHub | Создание учетной записи, вход, восстановление и сессия. Учетные записи, связи и сессии хранятся в Cloudflare D1; пароль хранится только как необратимый хеш. |
| Синхронизация прогресса | Набор ID завершенных точек, версия, контрольная сумма, время обновления и идентификаторы разрешения конфликтов | Объединение и восстановление прогресса между устройствами. D1 хранит данные, Durable Objects координируют синхронизацию; настройки интерфейса и маршрут просмотра не синхронизируются. |
| Привязка персонажа | Токен Skland или SKPORT, UID, сервер, имя персонажа и данные устройства, необходимые для официального интерфейса | Привязка, обновление авторизации и получение текущего положения. Токены шифруются AES-GCM в D1; временные данные и расшифрованные результаты могут кратко кэшироваться. |
| Текущее положение | Координаты, статус положения и необходимый идентификатор привязки | Показ положения и напоминания о близких точках. Данные поступают по запросу или WebSocket и кратко кэшируются в памяти; история перемещений и тепловая карта не сохраняются. |
| Изображения точек | Файл, тип и размер изображения, точка, отправитель, статус проверки, голоса и жалобы | Проверка и показ изображений. Файлы проверяются и при необходимости конвертируются в Cloudflare R2, метаданные хранятся в D1. |
| Комментарии | Текст, ответы, точка, профиль автора, голоса, жалобы, версии редактирования и статус проверки | Обсуждения, исправления, переводы и модерация. Записи находятся в D1; текст может проверяться OpenAI и переводиться Google Cloud Translation после одобрения. |
| Безопасность и лимиты | IP-адрес, путь, время, идентификатор запроса и необходимые заголовки | Защита от злоупотреблений и диагностика. Cloudflare ведет сетевые журналы; Upstash Redis или память Worker используют краткие окна лимитов и кэш. |

Вид карты, тема, язык, фильтры и состояние панели по умолчанию остаются только в браузере.

## Сторонняя обработка и трансграничная передача

Cloudflare предоставляет CDN, защиту, Workers, D1, R2, KV, Durable Objects, Queue и контейнеры; запросы и данные могут обрабатываться за пределами вашей страны. Upstash используется только для лимитов и краткого кэша. OpenAI проверяет отправленные комментарии и изображения; неопределенные случаи направляются на ручную проверку. Google Cloud Translation обрабатывает одобренные комментарии для перевода. Google, Discord и GitHub участвуют только при выбранном OAuth-входе, а Resend отправляет коды и необходимые письма учетной записи.

## Публичность и контроль UGC

Одобренные изображения и комментарии являются общедоступными. Вы можете отозвать доступный для отзыва материал, редактировать комментарий с повторной проверкой или запросить удаление. Подробности о правах и сроках см. в [Политике конфиденциальности](./privacy) и [Заявлении о UGC](./ugc).

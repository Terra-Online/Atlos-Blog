本清单系[《隐私权政策》](./privacy)之提炼与补充。仅在您使用相应功能时，我们才会处理对应数据。

## 核心业务功能与信息收集明细

| 业务功能 | 处理的数据 | 用途 | 处理与存储方式 | 保留方式 |
| :--- | :--- | :--- | :--- | :--- |
| **账户注册与登录** | 电子邮箱、昵称、头像编号、密码哈希；或 Google、Discord、GitHub 返回的账户标识和基础资料 | 创建账户、身份验证、找回密码和维护会话 | 账户、关联身份和会话记录存储于 Cloudflare D1；密码仅保存不可逆哈希，不保存明文 | 账户存续期间保存；会话按有效期失效或在退出登录时撤销 |
| **点位进度同步** | 已完成点位的 ID 集合，以及版本、校验和、更新时间和同步冲突处理所需标识 | 跨设备合并、恢复探索进度，并生成汇总进度统计 | 进度持久化于 D1，并通过 Durable Objects 串行处理同步；不包含 UI 偏好或地图浏览轨迹 | 随账户保存，或按有效的数据删除请求处理 |
| **游戏角色绑定** | 森空岛或 SKPORT 授权令牌、角色 UID、服务器、角色昵称及为访问官方接口生成的设备资料 | 绑定指定角色、刷新授权并获取该角色当前位置 | 授权凭证使用 AES-GCM 加密后存储于 D1；绑定流程中的临时数据和解密结果可短期缓存 | 绑定期间保存；解绑时删除持久化绑定及相关缓存 |
| **实时位置显示** | 当前角色坐标、定位状态和必要的绑定标识 | 在当前地图会话中显示角色位置并提供接近点位提醒 | 通过请求或 WebSocket 从上游获取，并在服务端内存中作短期缓存；当前实现不收集或持久化历史移动轨迹 | 缓存失效、Worker 生命周期结束或解绑后，不再作为有效位置数据使用 |
| **点位图片** | 图片文件、图片类型和大小、关联点位、提交者账户、审核状态、赞同和举报记录 | 展示点位实景或指引图片，并进行审核与社区治理 | 图片经格式检查和必要的转码后存储于 Cloudflare R2；元数据存储于 D1；内容可发送至 OpenAI Moderation API 审核 | 按内容状态和删除申请处理；公开内容在撤回或删除前可被所有访问者查看 |
| **点位评论** | 评论正文、回复关系、关联点位、作者资料、投票、举报、编辑快照和审核状态 | 提供点位讨论、回复、纠错、翻译和社区治理 | 结构化记录存储于 D1；正文可发送至 OpenAI 审核；审核通过后可发送至 Google Cloud Translation 预生成常用译文或响应翻译请求 | 按内容状态和删除申请处理；必要的编辑快照用于审核与撤销 |
| **安全与限流** | IP 地址、请求路径、时间、请求标识及必要的请求头 | 防止接口滥用、排查故障和保护服务 | Cloudflare 处理基础网络日志；Upstash Redis 或 Worker 内存用于限流窗口和短期缓存 | 按基础设施配置和安全需要短期保留 |

地图视图、主题、语言、筛选器顺序、侧边栏状态等 UI 偏好默认只保存在浏览器本地，不属于点位进度同步内容。

## 第三方处理与跨境传输

1. **Cloudflare**：为网站提供 CDN、DDoS 防护、Worker、D1、R2、KV、Durable Objects、Queue 和容器处理能力。请求及存储数据可能在您所在国家或地区以外的节点处理。
2. **Upstash**：处理接口限流键和值及部分短期缓存，不承担账户进度或 UGC 的主要持久化存储。
3. **OpenAI**：审核您提交的评论和点位图片。审核失败或无法自动判断时，内容会转入人工复核，而非自动公开。
4. **Google Cloud Translation**：处理审核通过的评论文本，用于预生成部分常用语言译文或响应用户翻译请求，并缓存结果以减少重复调用。
5. **Google、Discord、GitHub**：仅在您选择相应 OAuth 登录方式时处理认证数据。
6. **Resend**：用于发送验证码、密码重置及必要的账户邮件。

各服务提供商依据其自身条款与隐私政策处理数据。我们不会向其提供与相应功能无关的数据。

## UGC 公开性与控制

* 经审核公开的点位图片、评论、作者公开资料及互动统计可被所有访问者查看。
* 上传图片前请移除真实姓名、联系方式、账号凭证、聊天记录等不应公开的信息。
* 提交者可在界面允许的状态下撤回待审内容，或对已公开内容发起删除申请；部分操作需要人工审核。
* 其他登录用户可以对公开内容投票或举报。被举报内容可能变更状态并进入复核流程。

关于内容规则与授权范围，请参阅[《UGC 内容声明》](./ugc)与[《社区守则》](./community-guidelines)。

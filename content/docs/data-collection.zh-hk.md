## 核心業務功能及資料收集詳情

| 業務功能 | 所處理的資料 | 用途 | 處理及儲存方式 | 保留方式 |
| :--- | :--- | :--- | :--- | :--- |
| **帳戶註冊及登入** | 電郵地址、暱稱、頭像編號、密碼雜湊；或 Google、Discord、GitHub 傳回的帳戶識別資料及基本資料 | 建立帳戶、身份驗證、重設密碼及維持工作階段 | 帳戶、關聯身份及工作階段紀錄儲存在 Cloudflare D1；密碼只保存不可逆雜湊，不會保存明文 | 在帳戶存續期間保存；工作階段會按有效期失效或在登出時撤銷 |
| **點位進度同步** | 已完成點位的 ID 集合，以及版本、校驗和、更新時間及處理同步衝突所需的識別資料 | 跨裝置合併及復原探索進度，並產生總體進度統計 | 進度持久儲存在 D1，並透過 Durable Objects 依序處理同步；不包括介面偏好或地圖瀏覽軌跡 | 隨帳戶保存，或按有效的資料刪除要求處理 |
| **遊戲角色綁定** | 森空島或 SKPORT 授權權杖、角色 UID、伺服器、角色暱稱，以及為存取官方介面而產生的裝置資料 | 綁定指定角色、更新授權並取得該角色目前位置 | 授權憑證以 AES-GCM 加密後儲存在 D1；綁定過程中的暫存資料及解密結果可作短期快取 | 綁定期間保存；解除綁定時會刪除持久綁定紀錄及相關快取 |
| **實時位置顯示** | 目前角色座標、定位狀態及所需綁定識別資料 | 在目前地圖工作階段中顯示角色位置，並提供鄰近點位提示 | 透過請求或 WebSocket 從上游取得，並在伺服器端記憶體中作短期快取；目前不會收集或持久儲存歷史移動軌跡 | 快取失效、Worker 生命週期結束或解除綁定後，不再作為有效位置資料使用 |
| **點位圖片** | 圖片檔案、圖片類型及大小、關聯點位、提交者帳戶、審核狀態、贊成及舉報紀錄 | 展示點位實景或指引圖片，並進行審核及社群管理 | 圖片經格式檢查及所需轉碼後儲存在 Cloudflare R2；中繼資料儲存在 D1；內容可傳送至 OpenAI Moderation API 審核 | 按內容狀態及刪除要求處理；公開內容在撤回或刪除前可供所有訪客查看 |
| **點位評論** | 評論正文、回覆關係、關聯點位、作者資料、投票、舉報、編輯快照及審核狀態 | 提供點位討論、回覆、修正、翻譯及社群管理 | 結構化紀錄儲存在 D1；正文可傳送至 OpenAI 審核；通過審核後可傳送至 Google Cloud Translation，以預先產生常用譯文或回應翻譯請求 | 按內容狀態及刪除要求處理；所需編輯快照用於審核及撤回 |
| **安全及限流** | IP 地址、請求路徑、時間、請求識別資料及所需請求標頭 | 防止介面濫用、排查故障及保障服務 | Cloudflare 處理基礎網絡日誌；Upstash Redis 或 Worker 記憶體用於限流時段及短期快取 | 按基礎設施設定及安全需要短期保留 |

地圖視圖、主題、語言、篩選器次序、側邊欄狀態等介面偏好，預設只保存在瀏覽器本機，不屬於點位進度同步內容。

## 第三方處理及跨境傳輸

1. **Cloudflare**：為網站提供 CDN、DDoS 防護、Worker、D1、R2、KV、Durable Objects、Queue 及容器處理功能。請求及儲存資料可能在閣下所在國家或地區以外的節點處理。
2. **Upstash**：處理介面限流鍵值及部分短期快取，不會承擔帳戶進度或 UGC 的主要持久儲存。
3. **OpenAI**：審核閣下提交的評論及點位圖片。如審核失敗或無法自動判斷，內容會轉交人工覆核，而不會自動公開。
4. **Google Cloud Translation**：處理已通過審核的評論文字，用於預先產生部分常用語言譯文或回應用戶翻譯請求，並快取結果以減少重複呼叫。
5. **Google、Discord、GitHub**：只會在閣下選用相關 OAuth 登入方式時處理認證資料。
6. **Resend**：用於發送驗證碼、密碼重設及所需帳戶電郵。

各服務供應商會按其本身條款及私隱政策處理資料。我們不會向其提供與相關功能無關的資料。

## UGC 的公開性及控制方式

* 經審核公開的點位圖片、評論、作者公開資料及互動統計可供所有訪客查看。
* 上載圖片前，請移除真實姓名、聯絡方式、帳戶憑證、聊天紀錄等不應公開的資料。
* 提交者可在介面容許的狀態下撤回待審內容，或就已公開內容提出刪除要求；部分操作須由人工審核。
* 其他已登入用戶可就公開內容投票或舉報。被舉報內容可能會變更狀態並進入覆核程序。

有關內容規則及授權範圍，請參閱[《UGC 內容聲明》](./ugc)及[《社群守則》](./community-guidelines)。

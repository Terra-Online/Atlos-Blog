## 核心功能資料

帳戶及登入會處理電郵、暱稱、頭像編號、密碼雜湊，或 Google、Discord、GitHub 回傳的識別及公開資料，並保存於 D1。進度同步只處理已完成點位 ID、版本、校驗和、更新時間及衝突處理識別；UI 偏好與瀏覽軌跡不會同步。角色綁定會處理 Skland 或 SKPORT 權杖、UID、伺服器、角色名稱和必要裝置資料，權杖以 AES-GCM 加密保存。即時位置只作短期請求、WebSocket 或記憶體快取處理，不保存移動歷史或熱力圖。

圖片檔及其中繼資料用於展示和審核，圖片保存於 R2、中繼資料保存於 D1；評論、回覆、投票、舉報及審核狀態保存於 D1。圖片和評論可送交 OpenAI Moderation API；已通過審核的評論可由 Google Cloud Translation 翻譯。Cloudflare 提供基礎設施，Upstash 提供限流短期快取，Resend 發送帳戶電郵。已通過審核的圖片和評論為公開內容。

歡迎使用 **Open Endfield Map**。為協助閣下清晰、直觀地了解我們使用各核心業務功能時收集和使用個人資訊之狀況，我們制定了本清單。

> **提示**：本清單為[《私隱政策》](./privacy)的摘要與補充。我們秉持「本地優先」與「最小必要」原則，只有在閣下主動開啟特定雲端或跨裝置功能時，才會收集對應的數據。

| 業務功能 | 收集的個人資訊欄位 | 收集目的 | 處理依據 | 處理方式與儲存位置 | 儲存期限 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **賬戶註冊與管理** | 用戶名、電郵地址、密碼憑證 | 用於建立和驗證 OEM 賬戶，為閣下提供設定與進度的跨裝置同步服務。 | **履行合約** / **用戶同意** | 密碼經強雜湊演算法（單向不可逆）加密。數據持久化儲存於 Cloudflare D1 資料庫中。 | 賬戶存續期間保留；註銷後徹底刪除。 |
| **森空島或 SKPORT 賬戶授權** | 森空島或 SKPORT 身份憑證（如 `cred` / `token`） | 獲取存取鷹角網絡與 Gryphline 官方 API 的權限，以實現遊戲內座標同步等高級功能。 | **明確同意** | 憑證加密後，透過我們的邊緣節點請求。憑證僅在 D1 資料庫或 Upstash 快取中加密流轉。**絕不用於讀取除地圖位置外之任何資訊或資產。** | 僅在功能開啟及綁定期間保留。閣下可隨時手動解除綁定，解除後伺服器將立即且徹底銷毀該憑證。 |
| **實時位置同步（僅自身可見）** | 遊戲角色 UID、伺服器資訊、單點實時座標 (X, Y, Z) | 區分不同角色的地圖進度，並在前端互動式地圖上渲染玩家目前的實時位置。 | **履行合約** / **明確同意** | 僅作為臨時狀態在記憶體和 Serverless 快取中流轉。**除非閣下主動授權參與熱力圖計劃，否則我們絕不進行歷史軌跡之持久化儲存。** | 工作階段結束後、解除綁定或前端頁面關閉後自動銷毀。 |
| **路線記錄與社區熱力圖貢獻** | 歷史移動軌跡（座標序列）、特定區域停留時間 | 用於分析遊戲內熱門探索區域、最佳化尋路路線推薦，並生成全局或區域聚合熱力圖（Heatmap）供全體社區參考。 | **明確同意** | 軌跡數據在加密上傳至 D1 資料庫前或入庫時，將立即進行匿名化處理，嚴格剝離與閣下 OEM 賬戶、遊戲 UID 相關之個人身份標識，僅以聚合座標集形式儲存。 | 原始附帶身份標識的軌跡流在完成去識別化處理後即刻銷毀；匿名聚合後的熱力圖基準數據將長期保留。 |
| **地圖互動與 UGC 貢獻** | 自訂標註點座標、評論文本、第三視角截圖、編輯歷史 | 支撐地圖的維基與共創體系，展示社區用戶之修改建議和路線規劃。 | **用戶同意** / **合法利益** | 經過自動化合規審核（如 OpenAI Moderation）後，關聯閣下賬戶標識公開展示。詳細規範請參閱[《UGC 內容聲明》](./ugc)。 | 只要賬戶存在或未主動刪除則一直保留；公開貢獻可能以歸檔形式長期留存。 |
| **安全防護與效能監控** | IP 地址、裝置型號、瀏覽器類型 (User-Agent)、存取時間戳記 | 識別異常流量（如機械人、DDoS 攻擊）、防禦 CSRF 攻擊、最佳化 CDN 邊緣節點分發策略。 | **合法利益**（保障網絡與資訊安全） | 日誌數據在基礎設施層自動生成，僅用於整體趨勢與安全分析，不與閣下的真實身份直接掛鉤。 | 通常在生成後 30 天內自動滾動覆蓋或永久刪除。 |

## 第三方共享與數據跨境傳輸

本項目採用全球化的去中心化架構（Serverless & Edge Computing）部署。當閣下使用本項目的同步或互動功能時，閣下的部分加密數據或請求特徵將被合法地傳輸至閣下所在國家/地區之外的伺服器進行處理：

1. **基礎設施與儲存流轉**：我們依賴 **Cloudflare**（全球 CDN 與邊緣資料庫）和 **Upstash**（全球分佈的 Serverless Redis）提供底層服務。閣下之數據可能會根據網絡最優路由策略，在境外節點被加密處理和持久化儲存。
2. **合規審核共享**：當閣下提交公開之 UGC 內容（如評論）時，相關文本數據可能被短期傳輸至 **OpenAI** 的審核介面（Moderation API）以進行自動化安全鑑別。我們承諾上述第三方提供商均受到嚴格的數據處理協議（DPA）約束，且不會將閣下之數據用於無關的商業化目的或 AI 模型訓練。

## UGC（用戶生成內容）特別風險提示

作為開源項目，社區內容共建是我們發展之基石。但請閣下務必知悉提供 UGC 內容的潛在風險：

* **公開可見性**：閣下上傳的第三視角截圖、評論與座標標註一旦提交，即視為授權我們公開展示，**所有存取本項目的用戶均可查看**。請絕對避免在截圖中包含閣下的真實姓名、聯絡方式、官方賬戶密碼明文等敏感私隱資訊。
* **獨立責任**：閣下應當對閣下產生的所有 UGC 負完全法律責任。因輕信他人提交的錯誤 UGC 而導致的任何遊戲內損失或糾紛，本項目概不負責。
* **協議約束**：關於 UGC 內容的所有權轉移、審核處置權限及免責條款，請務必在提交任何內容前仔細閱讀並確認同意完整的 **[《UGC 內容聲明》](./ugc)**。

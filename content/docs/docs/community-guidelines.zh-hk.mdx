如無特殊說明，本文件中之術語定義與解釋均以[《UGC 內容聲明》](./ugc)為準。

## 社群環境與行為原則

**終末地地圖集**致力建構一個開放、友善、準確且高效之遊戲地圖社群。為保障所有用戶之正常使用體驗，閣下於使用本項目服務時，應遵循以下基本原則：

- 尊重其他用戶與社群成員，保持內容客觀、準確且與遊戲相關；
- **別當混蛋！** 切勿蓄意破壞地圖數據、誤導其他玩家或干擾社群秩序；
- 遵守中華人民共和國及閣下所在地適用法律法規之規定；不濫用平台接口、上傳權限或同步功能；亦不傳播違法、騷擾、廣告或惡意內容。

## 上傳內容與使用規範

除《UGC 內容聲明》中已列明之禁止內容外，以下規則進一步適用於地圖截圖、評論、標記及相關互動內容。

| 內容類型 | 允許內容 | 禁止內容 |
| :--- | :--- | :--- |
| **截圖與圖像** | <ul><li>清晰展示遊戲點位、場景或路線之第三視角截圖</li><li>用於輔助說明地圖機制、地形結構或隱藏內容之圖片</li><li>經適度裁剪、壓縮或標註後之輔助指引圖</li></ul> | <ul><li>包含真實姓名、聯絡方式、帳戶密碼、聊天紀錄等敏感個人資訊之圖片</li><li>與《明日方舟：終末地》無關或無意義之圖片</li><li>帶有外掛宣傳、水印廣告、惡意二維碼或引流內容之圖片</li><li>涉及色情、暴力、血腥、恐怖主義、仇恨或政治敏感內容之圖片</li><li>明顯誤導玩家、偽造點位或惡意污染地圖數據之截圖</li></ul> |
| **評論、文字與描述** | <ul><li>客觀點位說明與路線建議</li><li>具建設性之修正回饋</li><li>與地圖探索相關經驗分享與社群交流</li></ul> | <ul><li>侮辱、誹謗、人身攻擊或惡意騷擾內容</li><li>歧視性、仇恨性或極端主義言論</li><li>外掛、作弊、私服或其他破壞遊戲公平性之傳播內容</li><li>垃圾訊息、惡意洗版或重複灌水</li><li>惡意程式碼、腳本、釣魚資訊或帳戶詐騙內容</li><li>未經授權公開他人私隱資料或帳戶資訊之文字內容</li></ul> |
| **點位與數據** | <ul><li>經實際驗證之遊戲內點位與座標</li><li>合理採集路線、探索路徑與地圖標註</li></ul> | <ul><li>明顯錯誤、惡意偽造或誤導性地圖資訊</li><li>大量重複、無意義或自動化生成數據</li><li>利用接口批量灌入垃圾點位或異常數據之行為</li></ul> |

## 私隱保護與審核機制

1. **公開可見性風險提示**：閣下上傳的第三視角截圖、評論與座標標註一經提交並經審核通過，即視為授權我們公開展示，**所有存取本項目之用戶均可查看**。請於上傳前仔細檢查，**絕對避免於截圖中包含或於評論中洩露閣下之個人私隱資料**。
2. **自動化與人工審核合規**：為保障社群環境，閣下提交的公開文字內容（如評論、截圖等）可能會被短暫傳輸至第三方自動化審核接口（如 **OpenAI Moderation API**）進行安全及合規鑑別。該鑑別僅用於攔截違規資訊，相關數據**絕不會**用於 AI 模型之訓練。

欢迎使用 **Open Endfield Map**。为了帮助您清晰、直观地了解我们在您使用各核心业务功能时收集和使用个人信息的情况，我们特制定本清单。

> **提示**：本清单系[《隐私权政策》](./privacy)的提炼与补充。我们秉持“本地优先”与“最小必要”原则，只有在您主动开启特定云端或跨设备功能时，才会收集对应的数据。

## 核心业务功能与信息收集明细

| 业务功能 | 收集的个人信息字段 | 收集目的 | 处理依据 | 处理方式与存储位置 | 存储期限 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **账户注册与管理** | 用户名、电子邮箱地址、密码凭证 | 用于创建和验证 OEM 账号，为您提供配置与进度的跨设备同步服务。 | **履行合同** / **用户同意** | 密码经强哈希算法（单向不可逆）加密。数据持久化存储于 Cloudflare D1 数据库中。 | 账号存续期间保留；注销后彻底删除。 |
| **森空岛或 SKPORT 账号授权** | 森空岛或 SKPORT 身份凭证（如 `cred` / `token`） | 获取访问鹰角网络与 Gryphline 官方 API 的权限，以实现游戏内坐标同步等高级功能。 | **明确同意** | 凭证加密后，通过我们的边缘节点请求。凭证仅在 D1 数据库或 Upstash 缓存中加密流转。**绝不用于读取除地图位置外的任何信息或资产。** | 仅在功能开启及绑定期间保留。您可随时手动解绑，解绑后服务器将立即且彻底销毁该凭证。 |
| **实时位置同步（仅自身可见）** | 游戏角色 UID、服务器信息、单点实时坐标 (X, Y, Z) | 区分不同角色的地图进度，并在前端交互式地图上渲染玩家当前的实时位置。 | **履行合同** / **明确同意** | 仅作为临时状态在内存和 Serverless 缓存中流转。**除非您主动授权参与热力图计划，否则我们绝不进行历史轨迹的持久化存储。** | 会话结束后、解除绑定或前端页面关闭后自动销毁。 |
| **路线记录与社区热力图贡献** | 历史移动轨迹（坐标序列）、特定区域停留时间 | 用于分析游戏内热门探索区域、优化寻路路线推荐，并生成全局或区域聚合热力图（Heatmap）供全体社区参考。 | **明确同意** | 轨迹数据在上传至 D1 数据库前或入库时，将立即进行匿名化处理，严格剥离与您 OEM 账户、游戏 UID 相关的个人身份标识，仅以聚合坐标集的形式存储。 | 原始附带身份标识的轨迹流在完成去标识化处理后即刻销毁；匿名聚合后的热力图基准数据将长期保留。 |
| **地图互动与 UGC 贡献** | 自定义标注点坐标、评论文本、第三视角截图、编辑历史 | 支撑地图的维基与共创体系，展示社区用户的修改建议和路线规划。 | **用户同意** / **合法利益** | 经过自动化合规审核（如 OpenAI Moderation）后，关联您的账户标识公开展示。详细规范请参阅[《UGC 内容声明》](./ugc)。 | 只要账户存在或未主动删除则一直保留；公开贡献可能以归档形式长期留存。 |
| **安全防护与性能监控** | IP 地址、设备型号、浏览器类型 (User-Agent)、访问时间戳 | 识别异常流量（如机器人、DDoS 攻击）、防御 CSRF 攻击、优化 CDN 边缘节点分发策略。 | **合法利益**（保障网络与信息安全） | 日志数据在基础设施层自动生成，仅用于整体趋势与安全分析，不与您的真实身份直接挂钩。 | 通常在生成后的 30 天内自动滚动覆盖或永久删除。 |

## 第三方共享与数据跨境传输

本项目采用全球化的去中心化架构（Serverless & Edge Computing）部署。当您使用本项目的同步或互动功能时，您的部分加密数据或请求特征将被合法地传输至您所在国家/地区之外的服务器进行处理：

1. **基础设施与存储流转**：我们依赖 **Cloudflare**（全球 CDN 与边缘数据库）和 **Upstash**（全球分布的 Serverless Redis）提供底层服务。您的数据可能会根据网络最优路由策略，在境外节点被加密处理和持久化存储。
2. **合规审核共享**：当您提交公开的 UGC 内容（如评论）时，相关文本数据可能被短期传输至 **OpenAI** 的审核接口（Moderation API）以进行自动化安全鉴别。我们承诺上述第三方提供商均受到严格的数据处理协议（DPA）约束，且不会将您的数据用于无关的商业化目的或 AI 模型训练。

## UGC（用户生成内容）特别风险提示

作为开源项目，社区内容的共建是我们发展的基石。但请您务必知悉提供 UGC 内容的潜在风险：

* **公开可见性**：您上传的第三视角截图、评论与坐标标注一旦提交，即视为授权我们公开展示，**所有访问本项目的用户均可查看**。请绝对避免在截图中包含您的真实姓名、联系方式、官方账号密码明文等敏感隐私信息。
* **独立责任**：您应当对您产生的所有 UGC 负完全法律责任。因轻信他人提交的错误 UGC 而导致的任何游戏内损失或纠纷，本项目概不负责。
* **协议约束**：关于 UGC 内容的所有权转移、审核处置权限及免责条款，请务必在提交任何内容前仔细阅读并确认同意完整的 **[《UGC 内容声明》](./ugc)**。

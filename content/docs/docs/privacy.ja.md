## はじめにおよび発効条項

**Open Endfield Map**（以下「当社」、「本プロジェクト」、または「OEM」といいます）へようこそ。当社は、お客様の個人情報のプライバシーとデータセキュリティの重要性を深く認識しており、最高水準でお客様の個人情報を保護することに尽力しています。本『プライバシーポリシー』は、お客様が本プロジェクトのサービスにアクセスして利用する際に、当社がどのようにお客様の個人データを収集、使用、保存、共有、および保護するかを明確かつ透明に説明するとともに、これらのデータに対してお客様が有する管理権を明確にすることを目的としています。

**本ポリシーを注意深くお読みください。本プロジェクトのサービスにアクセスまたは利用した場合、お客様は本プライバシーポリシーに記載されているデータ処理の運用を読み、理解し、同意したものとみなされます。**

> **注意**：本プロジェクトは、「ローカルファースト（Local-First）」の設計を採用しています。デフォルトの設定および未登録/未ログインの状態では、お客様のすべての利用データは**お客様のローカルブラウザ内にのみ保存**され、当社がコアなインタラクションデータを自発的に収集、アップロード、または分析することはありません。
> 
> 当社が収集するデータの全体的な概要については、『[個人情報収集および利用チェックリスト](./personal-info-checklist)』をご参照ください。

## 当社が収集する情報および収集方法

安全で安定した地図サービスおよびインタラクティブ機能を提供するため、当社は必要最小限の範囲内で以下の種類の情報のみを収集します。

### お客様が自発的に提供する情報

本プロジェクトの特定の高度な機能（コンテンツの貢献、アカウントの同期、**位置追跡**など）を利用することを選択した場合、以下の情報の提供をお願いすることがあります。
* **アカウント情報**：アカウントを登録する際、ユーザー名、メールアドレス、および暗号化処理されたパスワードの認証情報を収集し、ユーザープロフィールを作成します。
* **サードパーティのゲームサービス認証情報（Skland認証）**：お客様が「リアルタイム位置同期」などの高度な機能を自発的に有効にする場合、Sklandアカウントの認証情報（`cred`や`token`など）を提供していただく必要があります。この認証情報は、公式APIに対して**読み取り専用リクエスト**を行い、リアルタイムの座標を取得するためにのみ使用されます。当社は権限の境界を厳格に制限しており、**お客様のゲーム内資産やガチャ履歴を読み取ったり、権限外の操作や改ざんを行ったりすることは決してありません。** このデータは厳格に暗号化されており、お客様は個人設定でいつでも連携を解除でき、解除後データは直ちに破棄されます。
* **ユーザー生成コンテンツ（UGC）**：お客様が自発的に地図上にポイントのマーキング、修正の提案、編集履歴の送信、またはコメントの投稿を行った場合、これらのコンテンツデータおよび関連するアカウント識別子を収集します。
* **コミュニケーション記録**：サポートの要請や問題の報告のために、メールまたはGitHub Issueを通じて当社に連絡した場合、関連する通信記録を保存します。

### 当社が自動的に収集するテレメトリおよび運用データ

お客様が本プロジェクトのウェブサイトにアクセスされる際、当社のサーバーおよびセキュリティ保護機構は、サービスの可用性および安全性を確保するため、一定の技術的データを自動的に記録します。

* **ネットワークログデータ**：お客様の一部または全部のIPアドレス、ブラウザの種類およびバージョン、オペレーティングシステム、参照元URL、閲覧されたページのパス、ならびにタイムスタンプを含みます。
* **デバイスおよびセッション情報**：ログイン状態の維持、言語設定の保持、および基本的なパフォーマンス監視のための識別子。
* **コア進捗データ**：マップの閲覧状況やマーカーの状態を含み、複数のデバイス／環境間で進捗を同期する目的で使用されます。

### ローカル保存データ（当社が収集しない項目）

* **ローカルデータベース**：お客様のカスタム設定、フィルター等の非コアデータは、原則としてお客様の端末内の `LocalStorage` または `IndexedDB` に保存されます。**これらのデータはお客様が完全に管理するものであり、お客様が自らクラウド同期機能を有効化しない限り、当社が取得することはありません。**

## サードパーティサービスおよびデータの流通

効率的で安全なグローバルサービスを提供するため、本プロジェクトは一部のサードパーティ・インフラストラクチャおよびAPIサービスを統合しています。これらのサービスは、データ処理者（Data Processors）としてお客様の少量のデータを処理する場合があり、それぞれのプライバシーポリシーの対象となります。

| サードパーティサービス提供者 | 処理するデータ | サービスの用途 | 説明 |
| :--- | :--- | :--- | :--- |
| **Cloudflare** | IPアドレス、基本的なネットワークリクエストの特徴、暗号化されたアカウントおよび進捗データ。 | グローバルCDNアクセラレーション、DDoS防御、WorkerエッジコンピューティングおよびD1データベース。 | 悪意のある攻撃からウェブサイトを保護し、コンテンツの配信を高速化し、クロスプラットフォームでのデータの永続的な保存を実現するために使用されます。 |
| **OpenAI (Moderation API)** | お客様が送信した公開テキストコンテンツ（コメント、マーカーの説明など）およびマーカーのスクリーンショットコンテンツ。 | ユーザー生成コンテンツの自動化されたコンプライアンスおよびセキュリティ審査。 | 違反/悪意のある情報が含まれているかどうかを識別するためにのみ使用されます。OpenAI APIのポリシーに基づき、このようなデータが彼らのAIモデルのトレーニングに使用されることは**ありません**。 |
| **Upstash** | ハッシュ化されたIP識別子、一時的なセッショントークン、および一時的な座標の流通。 | サーバーレスデータベース（Serverless Redis）の高頻度キャッシュおよびAPIリクエストのレート制限。 | インターフェースの悪用を防ぎ、バックエンドサービスの応答速度と安定性を保障するために使用されます。 |
| **Google (OAuth)** | サードパーティの一意識別子（UID）、メールアドレス、公開されているユーザーアバターおよびニックネーム。 | Googleアカウントを利用したサードパーティの迅速な登録、ログイン、およびアカウントの関連付けの提供。 | 身元確認およびログインプロセスの簡素化にのみ使用されます。当社がお客様のGoogleアカウントのパスワードやその他のプライバシーデータにアクセスすることはできず、また絶対にアクセスしません。 |
| **Discord (OAuth)** | サードパーティの一意識別子（Discord ID）、メールアドレス、公開されているユーザーアバターおよびニックネーム。 | Discordアカウントを利用したサードパーティの迅速な登録、ログイン、およびアカウントの関連付けの提供。 | 身元確認および便利なログインにのみ使用されます。当社がお客様に代わってDiscordでメッセージを送信したり、お客様のプライベートな通信記録にアクセスしたりすることはできず、また行いません。 |

## お客様の情報の使用方法

当社は、以下の正当な目的および法的根拠に基づいて、お客様の個人データを処理します。

1. **サービスの提供および維持**（*契約の履行*）：クロスデバイスのデータ同期、リアルタイム座標の取得、ポイントのアップロードや表示などのコア機能を実現するため、お客様のアカウント、認証情報、およびコンテンツデータを処理します。
2. **セキュリティおよびコンテンツモデレーション**（*正当な利益*）：自動化ツールや手動の手段を利用してコンテンツを審査し、スパム、悪意のあるスクリプト、または違法コンテンツの拡散を防ぎます。
3. **パフォーマンスの最適化および分析**（*正当な利益*）：匿名化されたログデータを分析してユーザーのアクセストレンドを把握し、アプリケーションのネットワークパフォーマンスを最適化します。
4. **サービス通知**（*契約の履行*）：パスワードリセットのメールやアカウント状態の変更通知など、必要なトランザクション関連またはセキュリティ関連の通知をお客様のメールアドレスに送信します。

## データの保存、セキュリティ、および保持期間

### データセキュリティ保護措置

当社は、お客様のデータを保護するため、業界標準に準拠した物理的、技術的、および管理上の措置を講じています。これには以下が含まれますが、これらに限定されません。
* すべてのデータ転送は、最新のTLS/HTTPS暗号化プロトコルの使用を強制されます。
* パスワードおよび機密性の高い認証情報は強力なアルゴリズムを使用して一方向の暗号化保存が行われ、いかなる者（プロジェクトのメンテナーを含みます）もお客様の平文の認証情報を取得することはできません。
* 厳格なデータベースおよびエッジコンピューティング環境へのアクセス権限管理。

### データの保持期間

* **アカウントおよび同期データ**：お客様のアカウントがアクティブな状態である限り、登録情報およびクラウド同期データを保持し続けます。
* **サードパーティの認証情報データ**：お客様が自発的に連携している期間のみ保存され、連携をいつでも解除でき、解除後は直ちに破棄されます。
* **ログおよびテレメトリデータ**：サーバーのアクセスログおよびセキュリティブロックログは、通常、生成から30日以内に自動的にローリング上書きされるか、または永久に削除されます。
* **コンテンツの貢献**：Wiki/クラウドソーシングの性質を持つ地図プロジェクトであるため、お客様が送信した公開の変更やマーキングの記録は、地図の進化の履歴バージョンを保存するため、プロジェクトと共に存続する場合があります。お客様がアカウントを退会した場合でも、その貢献コンテンツは匿名またはアーカイブ形式で保持される可能性があります。

## Cookieおよび類似技術

本プロジェクトはCookieの乱用を厳格に制限し、必要なシナリオにおいてのみこれらの技術を使用します。

* **絶対に不可欠なCookie**：お客様のログインセッション（Session）を維持し、クロスサイトリクエストフォージェリ（CSRF）攻撃を防ぐために使用されます。
* **機能的なローカルストレージ**：当社は、UIの設定、地図ビューのズームレベル、およびローカルマーカーを保存するために、HTML5 Web Storage（`LocalStorage` / `IndexedDB`）を優先して使用します。
* **管理の選択**：お客様は、ブラウザの設定を通じていつでもCookieおよびローカルストレージをクリアまたは無効にすることができます。これらの機能を無効にした場合、アカウント同期など、認証に依存する機能が使用できなくなる可能性があることにご注意ください。

## データの共有および開示

当社は、お客様の個人データをいかなる第三者にも販売または貸与**しないことをお約束します**。当社は、以下の極めて限定的な状況においてのみデータを共有します。

1. **サービス提供者へのコンプライアンス**：「最小限の必要性の原則」に基づき、本ポリシー第3節で言及された信頼できるサードパーティのインフラストラクチャと、サービスの運用を維持するために必要なデータを共有します。
2. **法的コンプライアンスおよび強制的な要求**：適用される法律、規制、有効な召喚状、裁判所の命令、またはその他の法的手続きを遵守するために必要であると当社が確信する場合。
3. **正当な権利の保護**：潜在的なセキュリティの脅威、詐欺行為、本プロジェクトのシステムに対する悪意のある攻撃を調査、防止、または対処するため、あるいは本プロジェクトおよび公衆の財産と生命の安全を保護するため。

## お客様のデータに関する権利

本項の内容は、関連するプライバシー法規に適用されます。お住まいの司法管轄区に応じて、お客様はご自身の個人データに対して広範な管理権を有します。当社のデータベースおよびキャッシュレイヤーに保存されているデータに関して、お客様は以下の権利を有します。

* **アクセス権およびデータポータビリティ権**：当社が保持するお客様に関する個人データのコピーの取得を要求する権利。
* **訂正権**：データが不正確または不完全である場合、当社に修正を要求するか、または個人パネルで自ら修正を行う権利。
* **削除権（忘れられる権利）**：サードパーティの認証情報の連携をいつでも解除でき、アカウントおよび関連する個人を特定できる情報の完全な削除を申請する権利。
* **同意の撤回権**：お客様の同意に基づいて行われるデータ処理活動について、いつでもその同意を撤回する権利。

**権利の行使方法**：
お客様は、OEMの個人プロフィールパネルで大部分の管理操作を直接完了することができます。さらなるサポートが必要な場合、上記の権利を行使するには、`privacy@opendfieldmap.org` 宛てに電子メールを送信するか、当社のGitHubオープンソースリポジトリでIssueを提出してください。ご請求を受領してから180営業日以内に対応いたします。

お客様のローカルブラウザ内に完全に保存されているデータについては、お客様ご自身でブラウザのキャッシュをクリアすることで削除できます。

## 引言

欢迎使用 **Open Endfield Map**（以下简称“我们”、“本项目”或“OEM”）。本政策说明您访问地图、注册账户、同步点位进度、提交社区内容或绑定游戏角色时，我们如何处理相关数据。

本项目对客户端交互状态采取本地优先设计，但这不表示所有访问均在离线环境完成。地图资源、公共 UGC、登录和其他 API 请求仍会经过我们的服务器及基础设施提供商。

有关各功能处理字段的概览，请参阅[《个人信息收集与使用清单》](./data-collection)。

## 我们处理的信息

### 您主动提供的信息

* **账户资料**：电子邮箱、昵称、头像编号，以及邮箱密码注册时生成的密码哈希。
* **第三方登录资料**：当您选择 Google、Discord 或 GitHub 登录时，相应平台返回的账户标识、电子邮箱和公开资料。我们不会取得您的第三方平台密码。
* **游戏角色绑定资料**：当您主动绑定森空岛或 SKPORT 角色时，我们处理授权令牌、角色 UID、服务器、角色昵称及访问官方接口所需的设备资料。凭证以密文存储，用于获取角色和当前位置、刷新授权及维持绑定。
* **用户生成内容（UGC）**：您提交的点位图片、评论、回复，以及与编辑、投票、举报、撤回和删除申请有关的记录。
* **沟通记录**：您通过邮箱、GitHub 或社区渠道联系我们时提供的信息。

### 使用服务时产生的信息

* **网络与安全信息**：IP 地址、请求时间、路径、请求标识、User-Agent 及 Cloudflare 为提供安全防护和故障排查处理的网络特征。
* **登录与会话信息**：用于维持登录状态的会话记录、Cookie 和令牌。
* **云端点位进度**：已完成点位的 ID，以及同步所需的版本、校验和、更新时间和操作标识。
* **汇总进度统计**：每个点位的完成次数和同步用户总数。统计服务依据进度增减量更新汇总，不接收用于生成统计的用户 ID。
* **实时位置**：启用定位功能时，从官方服务取得的当前角色坐标和连接状态。当前实现不收集或持久化历史移动轨迹。

### 仅保存在本地的状态

主题、语言、侧边栏状态、筛选器顺序、图层显示偏好、地图中心与缩放层级、公告阅读状态等默认保存在浏览器本地。登录不会自动把这些 UI 偏好上传到云端。

## 第三方服务与数据流转

| 服务提供商 | 可能处理的数据 | 用途 |
| :--- | :--- | :--- |
| **Cloudflare** | IP 地址、请求信息、账户和会话记录、进度、绑定记录、UGC 元数据及图片 | CDN、DDoS 防护、Worker、D1、R2、KV、Durable Objects、Queue 与图片处理 |
| **Upstash** | IP 或用户维度的限流标识、时间窗口记录及部分短期缓存 | API 限流和运行缓存 |
| **OpenAI** | 待审核的评论文本和点位图片 | 自动化内容安全审核；无法确定或调用失败时转入人工复核 |
| **Google Cloud Translation** | 审核通过的公开评论文本 | 预生成常用语言翻译、按需机器翻译和翻译缓存 |
| **Google、Discord、GitHub** | OAuth 账户标识、邮箱和公开资料 | 用户选择的第三方登录 |
| **Resend** | 收件邮箱、邮件内容和投递信息 | 验证码、密码重置及必要的账户邮件 |

我们不会向第三方出售或出租您的个人数据。上述提供商有各自的条款和隐私政策，数据可能在您所在国家或地区以外处理。

## 我们如何使用信息

1. 创建和维护账户、发送验证码与密码重置邮件；
2. 跨设备同步已完成点位、处理不同设备间的进度冲突，并更新汇总完成统计；
3. 绑定游戏角色、刷新授权并在当前会话中显示角色位置；
4. 接收、审核、展示和管理点位图片、评论及社区互动；
5. 为公开评论预生成部分常用语言译文，并提供按需机器翻译；
6. 实施限流、安全防护、故障排查和必要的服务统计；
7. 遵守适用法律，处理权利请求并保护用户、本项目和公众的合法权益。

## 存储、安全与保留

### 存储位置

账户、会话、进度、绑定和 UGC 结构化记录主要存储于 Cloudflare D1；UGC 图片存储于 Cloudflare R2；KV、Durable Objects、Cache API 和 Upstash Redis 承担协调、限流与短期缓存用途。

### 安全措施

* 数据传输使用 HTTPS/TLS；
* 账户密码保存为不可逆哈希；
* 游戏授权凭证使用 AES-GCM 加密后持久化；
* 接口设有身份验证、来源限制、速率限制和内容审核流程。

任何网络服务都无法保证绝对安全。请勿向任何人泄露密码、验证码、会话令牌或游戏授权凭证。

### 保留方式

* **账户与点位进度**：通常随账户保存，直至账户或相关数据被删除。
* **登录会话**：按会话有效期失效，或在退出登录、撤销会话时终止。
* **游戏角色绑定**：绑定期间保存；解绑会删除 D1 中的绑定记录并清除相关缓存。
* **实时位置**：仅在连接和短期缓存中处理，不作为历史轨迹持久化。
* **UGC**：按审核状态、撤回或删除申请处理。评论编辑会保留必要快照，以支持审核和撤销。
* **安全与限流记录**：按基础设施配置和安全需要短期保留。

## Cookie 与本地存储

登录 Cookie 用于维持会话；`LocalStorage` 等浏览器存储用于保存点位完成状态和客户端偏好。清除浏览器站点数据不会自动删除已经同步到服务器的账户、进度、绑定或 UGC。

详细说明请参阅[《Cookie 与本地存储政策》](./cookie)。

## 数据共享与公开展示

我们仅在以下范围内共享或披露数据：

1. 向上述服务提供商传输完成对应功能所需的最少数据；
2. 经审核公开展示您主动提交的点位图片、评论、作者公开资料及互动统计；
3. 在法律要求、有效法律程序或保护用户与服务安全所必需时披露；
4. 在取得您另行同意的其他情形下处理。

请勿在 UGC 中提交不希望公开的个人信息。公开内容可被他人查看、引用或保存。

## 您的权利

根据适用法律，您可以请求访问、更正、导出或删除我们持有的个人数据，也可以撤回可撤回的同意：

* 在个人资料中修改昵称和头像；
* 禁用或解绑游戏角色，解绑会删除持久化凭证；
* 撤回待审核的 UGC，或对已公开内容发起删除申请；
* 清除浏览器本地存储以删除本地偏好与本地点位进度；
* 通过 `privacy@opendfieldmap.org` 请求处理无法在产品内完成的账户或数据事项。

为防止冒用，我们可能要求您验证账户身份。部分公开内容因争议处理、安全审计或法律义务可能无法立即删除；我们会说明适用限制。

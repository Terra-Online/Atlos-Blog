## 引言

歡迎使用 **Open Endfield Map**（以下簡稱「我們」、「本項目」或「OEM」）。本政策說明閣下瀏覽地圖、註冊帳戶、同步點位進度、提交社群內容或綁定遊戲角色時，我們如何處理相關資料。

本項目對用戶端互動狀態採用本機優先設計，但這不表示所有存取均在離線環境中完成。地圖資源、公開 UGC、登入及其他 API 請求仍會經由我們的伺服器及基礎設施服務供應商處理。

有關各項功能所處理欄位的概覽，請參閱[《個人資料收集及使用清單》](./data-collection)。

---

## 我們處理的資料

### 閣下主動提供的資料

* **帳戶資料**：電郵地址、暱稱、頭像編號，以及使用電郵及密碼註冊時所產生的密碼雜湊。
* **第三方登入資料**：如閣下選用 Google、Discord 或 GitHub 登入，我們會處理相關平台傳回的帳戶識別資料、電郵地址及公開資料。我們不會取得閣下在第三方平台的密碼。
* **遊戲角色綁定資料**：如閣下主動綁定森空島或 SKPORT 角色，我們會處理授權權杖、角色 UID、伺服器、角色暱稱及存取官方介面所需的裝置資料。憑證以密文儲存，用於取得角色及目前位置、更新授權及維持綁定。
* **用戶生成內容（UGC）**：閣下提交的點位圖片、評論、回覆，以及與編輯、投票、舉報、撤回及刪除要求相關的紀錄。
* **通訊紀錄**：閣下透過電郵、GitHub 或社群渠道聯絡我們時所提供的資料。

### 使用服務時產生的資料

* **網絡及安全資料**：IP 地址、請求時間、路徑、請求識別資料、User-Agent，以及 Cloudflare 為提供安全防護及排查故障而處理的網絡特徵。
* **登入及工作階段資料**：用於維持登入狀態的工作階段紀錄、Cookie 及權杖。
* **雲端點位進度**：已完成點位的 ID，以及同步所需的版本、校驗和、更新時間及操作識別資料。
* **實時位置**：啟用定位功能時，從官方服務取得的目前角色座標及連線狀態。目前不會收集或持久儲存歷史移動軌跡。

### 只保存在本機的狀態

主題、語言、側邊欄狀態、篩選器次序、圖層顯示偏好、地圖中心及縮放層級、公告閱讀狀態等，預設保存在瀏覽器本機。登入不會自動將該等介面偏好上載至雲端。

## 第三方服務及資料流轉

| 服務供應商 | 可能處理的資料 | 用途 |
| :--- | :--- | :--- |
| **Cloudflare** | IP 地址、請求資料、帳戶及工作階段紀錄、進度、綁定紀錄、UGC 中繼資料及圖片 | CDN、DDoS 防護、Worker、D1、R2、KV、Durable Objects、Queue 及圖片處理 |
| **Upstash** | IP 或用戶層面的限流識別資料、時段紀錄及部分短期快取 | API 限流及系統運作快取 |
| **OpenAI** | 等待審核的評論文字及點位圖片 | 自動化內容安全審核；未能確定或呼叫失敗時會交由人工覆核 |
| **Google Cloud Translation** | 已通過審核的公開評論文字 | 預先產生常用語言譯文、按需要提供機器翻譯及快取譯文 |
| **Google、Discord、GitHub** | OAuth 帳戶識別資料、電郵地址及公開資料 | 用戶選用的第三方登入方式 |
| **Resend** | 收件電郵地址、郵件內容及傳送資料 | 驗證碼、密碼重設及所需帳戶電郵 |

我們不會向第三方出售或出租閣下的個人資料。上述服務供應商各有其條款及私隱政策，資料可能在閣下所在國家或地區以外處理。

## 我們使用資料的方式

1. 建立及維護帳戶、發送驗證碼及密碼重設電郵；
2. 跨裝置同步已完成點位，並處理不同裝置之間的進度衝突；
3. 綁定遊戲角色、更新授權，並在目前工作階段中顯示角色位置；
4. 接收、審核、展示及管理點位圖片、評論及社群互動；
5. 為公開評論預先產生部分常用語言譯文，並按需要提供機器翻譯；
6. 實施限流、安全防護、故障排查及所需服務統計；
7. 遵守適用法律、處理權利要求，並保障用戶、本項目及公眾的合法權益。

## 儲存、安全及保留

### 儲存位置

帳戶、工作階段、進度、綁定及 UGC 結構化紀錄主要儲存在 Cloudflare D1；UGC 圖片儲存在 Cloudflare R2；KV、Durable Objects、Cache API 及 Upstash Redis 則用於協調、限流及短期快取。

### 安全措施

* 資料傳輸使用 HTTPS/TLS；
* 帳戶密碼以不可逆雜湊方式保存；
* 遊戲授權憑證以 AES-GCM 加密後持久儲存；
* 介面設有身份驗證、來源限制、速率限制及內容審核程序。

任何網絡服務均無法保證絕對安全。請勿向任何人披露密碼、驗證碼、工作階段權杖或遊戲授權憑證。

### 保留方式

* **帳戶及點位進度**：一般會隨帳戶保存，直至帳戶或相關資料被刪除。
* **登入工作階段**：按工作階段有效期失效，或在登出及撤銷工作階段時終止。
* **遊戲角色綁定**：在綁定期間保存；解除綁定時會刪除 D1 中的綁定紀錄，並清除相關快取。
* **實時位置**：只會在連線及短期快取中處理，不會作為歷史軌跡持久儲存。
* **UGC**：按審核狀態、撤回或刪除要求處理。評論編輯會保留所需快照，以支援審核及撤回。
* **安全及限流紀錄**：按基礎設施設定及安全需要短期保留。

## Cookie 及本機儲存

登入 Cookie 用於維持工作階段；`LocalStorage` 等瀏覽器儲存則用於保存點位完成狀態及用戶端偏好。清除瀏覽器網站資料，不會自動刪除已同步至伺服器的帳戶、進度、綁定或 UGC。

詳細說明請參閱[《Cookie 及本機儲存政策》](./cookie)。

## 資料共享及公開展示

我們只會在以下範圍內共享或披露資料：

1. 向上述服務供應商傳送完成相關功能所需的最少資料；
2. 經審核後公開展示閣下主動提交的點位圖片、評論、作者公開資料及互動統計；
3. 按法律要求、有效法律程序，或在保障用戶及服務安全所必需的情況下披露；
4. 在另行取得閣下同意的其他情況下處理。

請勿在 UGC 中提交不希望公開的個人資料。公開內容可被他人查看、引用或保存。

## 閣下的權利

根據適用法律，閣下可要求查閱、更正、匯出或刪除我們持有的個人資料，亦可撤回可撤回的同意：

* 在個人資料中修改暱稱及頭像；
* 停用或解除遊戲角色綁定；解除綁定時會刪除持久儲存的憑證；
* 撤回等待審核的 UGC，或就已公開內容提出刪除要求；
* 清除瀏覽器本機儲存，以刪除本機偏好及本機點位進度；
* 透過 `privacy@opendfieldmap.org` 要求處理無法在產品內完成的帳戶或資料事宜。

為防止冒用，我們可能要求閣下驗證帳戶身份。部分公開內容或會因爭議處理、安全審計或法律責任而無法立即刪除；我們會說明適用限制。

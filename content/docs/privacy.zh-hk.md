## 最新私隱處理方式

我們處理帳戶、OAuth 身份與公開資料、角色綁定資料、UGC、已完成點位 ID 與同步中繼資料、IP 及技術日誌、啟用綁定時的目前座標，以及投票、舉報和審核狀態。主題、語言、篩選器和地圖視圖通常只保存於瀏覽器。資料用於帳戶、進度同步、位置顯示、UGC 審核及展示、安全、限流和功能改善。

帳戶、工作階段、進度、綁定和 UGC 保存於 Cloudflare D1，圖片保存於 R2；綁定權杖以 AES-GCM 加密，密碼只保存不可逆雜湊，資料以 HTTPS/TLS 傳輸。我們不出售個人資料，亦不作定向廣告。Cloudflare、Upstash、OpenAI、Google Cloud Translation、Google/Discord/GitHub OAuth 及 Resend 會按功能處理相應資料，並可能在境外處理。

已通過審核的圖片、評論、公開作者資料和互動統計可供訪客查看。閣下可要求查閱、更正或刪除伺服器資料，亦可在產品允許時撤回或刪除 UGC；清除瀏覽器資料不會自動刪除伺服器資料。

## 我們收集之資料及收集方式

為向閣下提供安全及穩定之地圖服務與互動功能，我們僅於必要範圍內收集以下類型之資料：

### 閣下主動提供之資料

當閣下選擇使用本項目之特定高級功能（如內容貢獻、賬戶同步、位置追蹤）時，我們可能需要閣下提供以下資料：
* **賬戶資料**：當閣下註冊賬戶時，我們可能會收集閣下之電郵地址、經過強雜湊處理之密碼憑證以及用戶名，以為閣下建立用戶檔案。
* **第三方遊戲服務憑證（森空島授權）**：當閣下主動開啟「實時位置同步」等高級功能時，我們需要閣下提供森空島賬戶之身份憑證（如 `cred` 或 `token`）。該憑證僅用於向官方 API 發起**唯讀請求**以獲取實時座標。本項目嚴格限定權限邊界，**絕不會讀取閣下遊戲內資產、抽卡記錄，或進行任何越權、篡改操作。** 此數據經過嚴格加密，閣下可隨時在個人設定中解除綁定，解除後數據將即刻銷毀。
* **用戶生成內容（UGC）**：當閣下主動在地圖上提交點位標註、糾錯建議、編輯記錄或發表評論時，我們會收集上述內容數據以及相關之賬戶標識。
* **溝通記錄**：當閣下透過電郵或 GitHub Issue 與我們聯絡以獲取支援或反饋問題時，我們將保存相關通訊記錄。

### 本項目自動收集之遙測與運行數據

當閣下訪問本項目網站時，我們的伺服器及安全防護機制會自動記錄部分技術資料，以確保服務的可用性與安全性：

* **網絡日誌數據**：包括閣下的部分或全部 IP 地址、瀏覽器類型及版本、操作系統、來源／引薦網址（URL）、所訪問的頁面路徑及時間戳。
* **裝置與會話資訊**：用於維持登入狀態、語言偏好及基礎效能監測的識別符。
* **核心進度資料**：包括閣下的地圖瀏覽進度及標記狀態，以維持相關資料於不同裝置／環境之間的同步。

### 本地儲存數據（非收集項目）

* **本地資料庫**：閣下的自訂偏好設定、篩選器等非核心資料，預設儲存於閣下裝置的 `LocalStorage` 或 `IndexedDB` 之中。**該等資料由閣下完全控制；除非閣下主動啟用雲端同步功能，否則我們無法存取。**

## 第三方服務與數據流轉

為提供高效且安全之全球化服務，本項目整合了部分第三方基礎設施與 API 服務。該等服務可能作為數據處理者（Data Processors）處理閣下之少量數據，並受其各自私隱政策之約束：

| 第三方服務提供商 | 處理數據 | 服務用途 | 說明 |
| :--- | :--- | :--- | :--- |
| **Cloudflare** | IP 地址、基礎網絡請求特徵、加密後之賬戶與進度數據。 | 全球 CDN 加速、DDoS 防護、Worker 邊緣計算及 D1 資料庫。 | 用於保護網站免受惡意攻擊、加速內容分發以及實現數據之跨端持久化儲存。 |
| **OpenAI (Moderation API)** | 閣下提交之公開文本內容（如評論、標註描述）以及點位截圖內容。 | 用戶生成內容之自動化合規與安全審核。 | 僅用於鑑別是否包含違規/惡意資訊。根據 OpenAI API 政策，此類數據**不會**被用於其 AI 模型之訓練。 |
| **Upstash** | 經過雜湊處理之 IP 標識符、臨時工作階段權杖及臨時座標流轉。 | 無伺服器資料庫（Serverless Redis）高頻快取與 API 請求限流。 | 用於防止介面濫用，保障後端服務之響應速度與穩定性。 |
| **Google (OAuth)** | 第三方唯一標識符（UID）、電郵地址、公開之用戶頭像及暱稱。 | 提供 Google 賬戶之第三方快捷註冊、登入與賬戶關聯。 | 僅用於驗證身份並簡化登入流程。本項目無法獲取也絕對不會存取閣下之 Google 賬戶密碼或其他私隱數據。 |
| **Discord (OAuth)** | 第三方唯一標識符（Discord ID）、電郵地址、公開之用戶頭像及暱稱。 | 提供 Discord 賬戶之第三方快捷註冊、登入與賬戶關聯。 | 僅用於身份驗證和便捷登入。本項目無法且不會代表閣下在 Discord 發送訊息或存取閣下之私人通訊記錄。 |

## 我們如何使用閣下之資料

我們基於以下合法目的及法律依據處理閣下之個人數據：

1. **提供與維護服務**（*履行合約*）：處理閣下之賬戶、憑證和內容數據，以實現數據跨裝置同步、實時座標獲取、點位上傳展示等核心功能。
2. **安全與內容審核**（*合法利益*）：利用自動化工具和人工手段審核內容，防止垃圾資訊、惡意指令碼或違法內容之傳播。
3. **效能最佳化與分析**（*合法利益*）：分析去識別化之日誌數據，了解用戶存取趨勢，從而最佳化應用之網絡效能。
4. **服務通知**（*履行合約*）：向閣下之郵箱發送必要之交易類或安全類通知，如密碼重設電郵、賬戶狀態變更提醒。

## 資料儲存、安全與保留期限

### 數據安全保護措施
本項目實施了符合行業標準之物理、技術和管理措施來保護閣下之數據。包括但不限於：
* 所有數據傳輸均強制使用現代 TLS/HTTPS 加密協定。
* 密碼與敏感憑證使用強演算法進行單向加密或密文儲存，任何人（包括項目維護者）均無法獲取閣下之明文憑證。
* 嚴格之資料庫與邊緣計算環境存取權限控制。

### 數據保留期限
* **賬戶與同步數據**：只要閣下之賬戶處於活動狀態，我們將一直保留閣下之註冊資訊和雲端同步數據。
* **第三方憑證數據**：僅在閣下主動綁定期間保存，隨時解除綁定，即刻銷毀。
* **日誌與遙測數據**：伺服器存取日誌和安全攔截日誌通常在生成後之 30 天內被自動滾動覆蓋或永久刪除。
* **內容貢獻**：作為維基/眾包性質之地圖項目，閣下提交之公開修改或標註記錄可能會與項目共存，以保留地圖演進之歷史版本。即使閣下註銷賬戶，該等貢獻內容也可能以匿名或歸檔形式保留。

## Cookies 及同類技術

本項目嚴格限制 Cookies 之使用，僅於必要情況下採用：

* **絕對必要的 Cookies**：用於維持閣下之登入工作階段（Session）和防止跨站請求偽造（CSRF）攻擊。
* **功能性本地儲存**：本項目優先使用 HTML5 Web Storage (`LocalStorage` / `IndexedDB`) 來保存閣下之 UI 偏好、地圖視圖層級及本地標記。
* **管理選擇**：閣下可隨時透過瀏覽器設定清除或停用 Cookie 及本地儲存。請注意，停用該等功能可能會導致閣下無法使用賬戶系統、座標同步等依賴認證之功能。

本款內容適用於相關私隱法規；根據閣下所在之司法管轄區，閣下對自身之個人數據享有廣泛之控制權。針對儲存在本項目資料庫與快取層上之數據，閣下擁有以下權利：

* **存取與匯出權**：閣下有權要求獲取本項目所持有關於閣下之個人數據副本。
* **更正權**：如果閣下之數據不準確或不完整，閣下有權要求進行修正或在個人面板自行修改。
* **刪除權（被遺忘權）**：閣下可隨時解除綁定第三方憑證，或申請徹底刪除賬戶及關聯之個人可識別資訊。

**行使權利方式：**  
閣下可透過發送電郵至 `privacy@opendfieldmap.org`，或於我們之 GitHub 開源倉庫提交 Issue 行使上述權利。我們將於收到請求後 180 個工作日內作出回應。
